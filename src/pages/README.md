# Pages 目录说明

本目录存放项目的特殊页面组件，通常是独立功能页面。

## 📄 ResumeGenerator.vue - 简历生成器

### 功能描述

一个在线简历生成器工具，用户可以通过填写表单创建专业的个人简历，并支持实时预览和导出PDF功能。

### 访问入口

1. **直接访问**：通过URL `/resume-generator` 访问
2. **从About页面**：在About页面（`/about`）右上角点击紫色的"简历生成器"按钮

### 主要功能

#### 1. 基本信息编辑

- 姓名
- 职位
- 邮箱
- 电话
- 地址

#### 2. 个人简介

- 支持多行文本输入
- 可以描述职业背景、技能特长和职业目标

#### 3. 工作经历管理

- 支持添加多个工作经历
- 每个经历包含：
  - 公司名称
  - 职位
  - 开始日期
  - 结束日期
  - 工作描述
- 支持删除不需要的经历

#### 4. 教育背景管理

- 支持添加多个教育背景
- 每个背景包含：
  - 学校名称
  - 专业/学位
  - 开始日期
  - 结束日期
- 支持删除不需要的教育背景

#### 5. 技能列表

- 支持添加多个技能
- 每行输入一个技能
- 在预览中以标签形式展示

#### 6. 实时预览

- 左侧填写，右侧实时预览
- 预览样式专业、美观
- 预览区域固定在视口，方便查看

#### 7. 导出PDF

- 点击"下载PDF"按钮
- 使用浏览器打印功能生成PDF
- 支持自定义文件名（使用填写的姓名）

### 使用方法

1. **访问页面**：
   - 从About页面点击右上角的纸张图标按钮，或
   - 直接访问 `/resume-generator`

2. **填写信息**：
   - 按照表单从上到下依次填写信息
   - 标记 `*` 的字段为建议必填项
   - 可以随时在右侧查看预览效果

3. **添加/删除经历**：
   - 点击"+ 添加工作经历"或"+ 添加教育背景"按钮添加新项
   - 点击每项右上角的"删除"按钮移除不需要的项

4. **导出简历**：
   - 点击预览区域右上角的"下载PDF"按钮
   - 在弹出的打印窗口中选择"保存为PDF"
   - 选择保存位置并确认

### 技术特点

#### 组件设计

- 使用 Vue 3 Composition API
- 响应式数据绑定，实时更新预览
- 组件化设计，易于维护和扩展

#### 响应式设计

- 桌面端：左右分栏布局（表单 | 预览）
- 平板/移动端：上下布局，预览区域固定
- 移动端优化：简化按钮显示，优化输入体验

#### 样式特性

- 渐变背景，视觉吸引力强
- 卡片式设计，层次分明
- 按钮悬停效果，交互友好
- 预览区域采用专业简历样式

#### 数据管理

- 使用 Vue 的 ref 进行响应式数据管理
- 使用 computed 属性处理技能列表
- 数组操作实现动态添加/删除功能

### 注意事项

1. **浏览器兼容性**
   - 建议使用现代浏览器（Chrome, Firefox, Safari, Edge）
   - 打印功能依赖浏览器的打印API

2. **数据安全**
   - 当前版本所有数据仅存储在浏览器内存中
   - 刷新页面会丢失数据
   - 建议定期下载备份

3. **移动端使用**
   - 在移动设备上建议使用横屏模式
   - PDF导出在移动端可能需要额外步骤
