# ☁️ 简历云端存储功能使用指南

## 🎯 功能概述

简历云端存储功能让您可以将简历数据安全地保存到七牛云对象存储中，实现跨设备访问和数据备份。无论您在哪台设备上访问，都可以随时读取您的简历数据。

## ✨ 核心特性

- **☁️ 云端存储** - 简历数据保存在七牛云，永久可访问
- **🔄 实时同步** - 支持手动保存和自动同步
- **🔐 数据安全** - 每个用户拥有唯一ID，数据隔离存储
- **📱 跨设备访问** - 在任何设备上都可以加载您的简历
- **💾 本地备份** - 云端和本地双重保存，数据更安全
- **🆔 自动识别** - 自动生成设备ID，无需注册登录

## 🚀 快速开始

### 第一步：确保七牛云配置正确

云端存储功能需要正确配置七牛云服务。请确保：

1. 已配置七牛云密钥（AccessKey 和 SecretKey）
2. 已创建存储空间（Bucket）
3. 已配置访问域名（Domain）

如果还未配置，请参考 [七牛云配置使用指南](./七牛云配置使用指南.md)

### 第二步：使用云端保存功能

1. 访问简历生成器页面：`http://localhost:5173/resume-generator`
2. 填写或编辑您的简历信息
3. 点击页面顶部的 **"☁️ 保存到云端"** 按钮
4. 等待保存完成，系统会提示保存成功

### 第三步：从云端加载简历

1. 在简历生成器页面顶部点击 **"📥 从云端加载"** 按钮
2. 确认要加载云端数据（会覆盖当前本地数据）
3. 等待加载完成，简历数据会自动填充到编辑器中

## 📋 详细功能说明

### 1. 保存到云端

**功能说明：**

- 将当前编辑的简历数据保存到七牛云存储
- 数据以JSON格式存储，包含完整的简历信息
- 每次保存都会更新云端的最新版本

**使用方法：**

1. 点击 **"☁️ 保存到云端"** 按钮
2. 等待上传完成（通常只需几秒钟）
3. 看到成功提示后，数据已安全保存

**保存的内容：**

- ✅ 基本信息（姓名、联系方式等）
- ✅ 个人简介
- ✅ 工作经历
- ✅ 教育背景
- ✅ 技能列表
- ✅ 项目经验
- ✅ 证书资质
- ✅ 头像图片（Base64格式）

### 2. 从云端加载

**功能说明：**

- 从七牛云读取您之前保存的简历数据
- 加载后会覆盖当前的本地数据
- 适用于换设备或清除了本地缓存的情况

**使用方法：**

1. 点击 **"📥 从云端加载"** 按钮
2. 确认要加载（建议先备份当前数据）
3. 等待加载完成，简历会自动填充

**注意事项：**

- ⚠️ 加载会覆盖本地数据，请谨慎操作
- 💡 建议在加载前先导出当前数据作为备份
- 🔍 如果云端没有数据，会提示您先保存

### 3. 云端同步状态

页面会显示云端同步的状态信息：

```
☁️ 上次云端保存：2小时前
```

这可以帮助您了解：

- 数据最后一次同步的时间
- 是否需要重新保存最新修改

### 4. 错误提示

如果保存或加载失败，系统会显示错误提示：

```
⚠️ [错误信息] ✕
```

常见错误及解决方法：

- **"保存失败：网络错误"** → 检查网络连接
- **"云端没有找到简历数据"** → 先保存数据到云端
- **"七牛云配置不完整"** → 检查七牛云配置

## 🔧 技术细节

### 数据存储结构

简历数据以JSON格式存储在七牛云：

```json
{
  "version": "1.0",
  "savedAt": "2025-10-11T12:00:00.000Z",
  "userId": "user_xxxxx",
  "data": {
    "fullName": "张三",
    "title": "前端开发工程师",
    "email": "zhangsan@example.com"
    // ... 其他简历数据
  },
  "metadata": {
    "userAgent": "Mozilla/5.0...",
    "savedFrom": "http://localhost:5173/resume-generator"
  }
}
```

### 存储路径

```
七牛云存储空间
└── resumes/
    └── user_[用户ID]/
        └── default.json  (默认简历)
```

### 用户ID生成规则

系统会自动为每个用户生成唯一ID：

```javascript
用户ID = user_[设备信息]_[时间戳]_[随机字符串]
```

- 首次访问时自动生成
- 保存在浏览器localStorage中
- 同一浏览器/设备始终使用相同ID
- 换设备或清除缓存后会生成新ID

### 数据安全性

- 🔐 **数据隔离**：每个用户ID对应独立的存储空间
- 🔒 **访问控制**：通过七牛云的访问控制保护数据
- 💾 **双重备份**：云端和本地localStorage同时保存
- ✅ **数据完整性**：上传前验证JSON格式正确性

## 🎓 使用建议

### 最佳实践

1. **定期保存**
   - 完成重要修改后立即保存到云端
   - 养成定期保存的习惯

2. **多设备使用**
   - 在新设备上先"从云端加载"
   - 修改后记得"保存到云端"

3. **数据备份**
   - 重要简历建议导出JSON文件备份
   - 加载云端数据前先备份本地数据

4. **版本管理**
   - 云端只保存最新版本
   - 如需保存多个版本，使用JSON导出功能

## ❓ 常见问题

### Q1: 为什么刷新浏览器后数据还在？

**A:** 简历数据有两份备份：

- 本地备份：浏览器localStorage（自动保存）
- 云端备份：七牛云存储（手动保存）

正常情况下刷新不会丢失数据。如果丢失，可以从云端加载。

### Q2: 我在手机上能访问电脑上的简历吗？

**A:** 理论上可以，但有条件：

- 需要在同一浏览器登录（使用相同的用户ID）
- 或者手动复制localStorage中的用户ID到手机
- 更推荐的方式是导出JSON文件传输

### Q3: 云端能保存多份简历吗？

**A:** 当前版本只支持保存一份默认简历（default.json）。
如需保存多份简历：

- 使用"导出JSON"功能保存到本地
- 给文件命名如：前端工程师简历.json、产品经理简历.json

### Q4: 云端存储是否收费？

**A:** 使用七牛云存储：

- 免费额度：10GB存储空间，10GB/月流量
- 简历JSON文件通常只有几KB
- 正常使用完全在免费范围内

### Q5: 数据会被其他人看到吗？

**A:** 不会，因为：

- 每个用户有唯一的用户ID
- 数据存储在独立的路径下
- 七牛云有访问控制机制
- 但请注意：不要泄露您的用户ID

### Q6: 如果换浏览器了怎么办？

**A:** 换浏览器会生成新的用户ID，无法直接访问之前的数据。
解决方案：

1. **在旧浏览器**：导出JSON文件作为备份
2. **在新浏览器**：导入JSON文件
3. **或者**：复制旧浏览器localStorage中的用户ID到新浏览器

### Q7: 云端保存失败怎么办？

**A:** 按以下步骤排查：

1. 检查网络连接是否正常
2. 检查七牛云配置是否正确
3. 查看浏览器控制台错误信息
4. 确认七牛云存储空间是否可用
5. 尝试重新保存

### Q8: 云端数据会永久保存吗？

**A:**

- 七牛云数据默认永久保存
- 除非手动删除或七牛云账户欠费
- 建议定期备份重要数据

## 🔍 故障排除

### 问题1：点击保存按钮没反应

**可能原因：**

- 七牛云配置未完成
- 网络连接问题
- JavaScript错误

**解决方法：**

1. 打开浏览器开发者工具（F12）
2. 查看Console标签的错误信息
3. 检查Network标签的网络请求
4. 验证七牛云配置是否正确

### 问题2：提示"云端没有找到简历数据"

**原因：**

- 您还没有保存过数据到云端
- 或者使用了不同的用户ID

**解决方法：**

- 先编辑简历并点击"保存到云端"
- 确认使用的是相同的用户ID

### 问题3：加载云端数据后内容不完整

**可能原因：**

- 上次保存时数据不完整
- JSON数据损坏

**解决方法：**

1. 检查云端JSON文件的内容
2. 如有备份，尝试导入备份文件
3. 重新编辑并保存

### 问题4：保存时提示"文件过大"

**原因：**

- 头像图片太大（Base64编码后）

**解决方法：**

1. 压缩头像图片（推荐400x400像素）
2. 使用JPG格式而非PNG
3. 确保图片文件小于1MB
