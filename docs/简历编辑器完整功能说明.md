# 简历编辑器完整功能说明

## 📋 功能概述

简历编辑器现已完善，支持完整的简历编辑、导出和AI定制功能。所有数据通过 Pinia Store 管理，自动保存到 localStorage。

## ✅ 已完成功能

### 1. 完整的简历编辑功能

#### 基本信息编辑

- ✅ 姓名
- ✅ 当前职位 (带岗位建议)
- ✅ **目标岗位** (用于AI定制简历)
- ✅ 邮箱
- ✅ 电话
- ✅ 地址

#### 详细内容编辑

- ✅ 个人简介 (支持富文本)
- ✅ 工作经历 (添加/删除/编辑)
- ✅ 教育背景 (添加/删除/编辑)
- ✅ **项目经验** (添加/删除/编辑)
  - 项目名称
  - 担任角色
  - 开始/结束日期
  - 项目描述 (支持富文本)
  - 技术栈 (支持多个技术)
  - 项目链接
- ✅ 技能列表 (支持多行输入)

### 2. 数据管理 (Pinia Store)

#### resumeStore 功能

- ✅ 自动保存草稿到 localStorage
- ✅ 最后保存时间记录
- ✅ 简历完成度百分比计算
- ✅ **目标岗位字段** (`targetJob`)

#### Store 方法

```javascript
// 工作经历

// 教育背景

// 技能管理

// 目标岗位

// 数据操作

exportJSON()
importJSON(jsonData)

```

### 3. PDF 导出功能

#### 导出方式

**方式一：从 DOM 元素导出**

```javascript
import { exportResumePDF } from '@/utils/pdfExporter'

// 导出指定元素
const element = document.querySelector('.resume-preview')
await exportResumePDF(element, '张三-前端工程师')
```

**方式二：从 Pinia Store 直接导出** ⭐ (新功能)

```javascript
import { exportResumeFromStore } from '@/utils/pdfExporter'
import { useResumeStore } from '@/stores/resumeStore'

const resumeStore = useResumeStore()

// 自动生成文件名：姓名-目标岗位-日期
await exportResumeFromStore(resumeStore)

// 自定义选项
await exportResumeFromStore(resumeStore, {
  fileName: '张三-高级前端工程师-简历',
  includeTargetJob: true, // 是否在PDF中显示目标岗位
})
```

#### PDF 导出选项

```javascript
{
  fileName: '自定义文件名',        // 文件名（不含扩展名）
  template: 'modern',              // 模板样式
  includeTargetJob: false,         // 是否显示目标岗位
  margin: [15, 15, 15, 15],       // 页边距 [上, 右, 下, 左]
}
```

## 🎯 目标岗位功能

### 使用场景

目标岗位字段用于未来的 AI 定制简历功能，可以与当前职位不同。

**示例场景:**

- 当前职位：前端工程师
- 目标岗位：资深前端工程师
- 目标岗位：全栈工程师
- 目标岗位：技术经理

### 在编辑器中使用

```vue
<template>
  <div class="form-group">
    <label>目标岗位</label>
    <JobSelector v-model="resumeData.targetJob" />
  </div>
</template>
```

### 在 Store 中访问

```javascript
const resumeStore = useResumeStore()

// 读取目标岗位
console.log(resumeStore.resumeData.targetJob)

// 设置目标岗位
resumeStore.setTargetJob('资深前端工程师')

// 或直接修改
resumeStore.resumeData.targetJob = '全栈工程师'
```

### 在 PDF 导出中使用

```javascript
// 在PDF中显示目标岗位
await exportResumeFromStore(resumeStore, {
  includeTargetJob: true,
})
```

## 🔧 使用示例

### 完整使用流程

```vue
<template>
  <div class="resume-page">
    <!-- 编辑器 -->
    <ResumeEditor />

    <!-- 导出按钮 -->
    <div class="actions">
      <button @click="exportPDF">导出 PDF</button>
      <button @click="exportWithTargetJob">导出带目标岗位的 PDF</button>
      <button @click="saveJSON">导出 JSON</button>
    </div>

    <!-- 预览 -->
    <ResumePreview />
  </div>
</template>

<script setup>
import { useResumeStore } from '@/stores/resumeStore'
import { exportResumeFromStore } from '@/utils/pdfExporter'
import ResumeEditor from '@/components/ResumeEditor.vue'
import ResumePreview from '@/components/ResumePreview.vue'

const resumeStore = useResumeStore()

// 导出 PDF
const exportPDF = async () => {
  const result = await exportResumeFromStore(resumeStore)
  if (result.success) {
    alert('PDF 导出成功！')
  } else {
    alert('导出失败：' + result.error.message)
  }
}

// 导出带目标岗位的 PDF
const exportWithTargetJob = async () => {
  await exportResumeFromStore(resumeStore, {
    includeTargetJob: true,
    fileName: `${resumeStore.resumeData.fullName}-${resumeStore.resumeData.targetJob}`,
  })
}

// 导出 JSON
const saveJSON = () => {
  resumeStore.exportJSON()
}
</script>
```

## 💡 最佳实践

### 1. 填写建议

- **姓名和职位**: 必填项，影响文件名生成
- **目标岗位**: 填写想要应聘的岗位，为AI优化做准备
- **个人简介**: 3-5句话，突出核心优势
- **工作描述**: 使用量化数据，如"性能提升40%"
- **项目经验**: 重点描述个人贡献，不要只写背景
- **技能列表**: 只列核心技能，避免列太多

### 2. 导出建议

```javascript
// 普通版本（给普通公司）
await exportResumeFromStore(resumeStore, {
  fileName: '张三-前端工程师',
  includeTargetJob: false,
})

// 定制版本（给目标公司）
await exportResumeFromStore(resumeStore, {
  fileName: '张三-高级前端工程师-字节跳动',
  includeTargetJob: true,
})
```

### 3. 数据备份

// 定期导出 JSON 备份
