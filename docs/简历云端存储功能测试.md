# ☁️ 简历云端存储功能测试指南

## 🎯 测试目标

验证简历云端存储功能是否正常工作，包括保存、加载、错误处理等核心功能。

## 📋 测试前准备

### 1. 确认七牛云配置

检查 `.env` 文件中的七牛云配置：

```bash
# 必需的配置项
QINIU_ACCESS_KEY=你的AccessKey
QINIU_SECRET_KEY=你的SecretKey
QINIU_BUCKET=你的存储空间名称
VITE_QINIU_DOMAIN=你的访问域名

# 启用调试模式（可选）
VITE_ENABLE_QINIU_DEBUG=true
```

### 2. 启动开发服务器

```bash
npm run dev
```

访问：`http://localhost:5173/resume-generator`

## 🔍 调试技巧

### 查看控制台日志

启用调试模式后，在浏览器控制台查看详细日志：

```javascript
// 查看服务初始化日志
[ResumeCloudService] 创建新用户ID {userId: "user_..."}

// 查看保存日志
💾 开始保存简历到云端...
[ResumeCloudService] 开始保存简历到云端 {resumeId: "default"}
✅ 简历已保存到云端 {key: "...", url: "...", size: 1234}

// 查看加载日志
📥 开始从云端加载简历...
[ResumeCloudService] 开始从云端加载简历 {resumeId: "default"}
✅ 简历已从云端加载 {version: "1.0", savedAt: "..."}
```

### 查看七牛云存储

登录七牛云控制台，查看存储空间：

1. 访问：https://portal.qiniu.com/kodo/bucket
2. 选择你的存储空间
3. 进入文件管理
4. 查看 `resumes/user_[你的用户ID]/` 目录
5. 应该能看到 `default.json` 文件

### 下载并查看JSON文件

在七牛云控制台：

1. 找到 `default.json` 文件
2. 点击下载
3. 使用文本编辑器打开
4. 检查数据结构是否正确
