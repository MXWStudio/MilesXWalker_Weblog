# 📸 岗位截图识别 - 快速参考

## 🚀 快速开始

### 1️⃣ 配置 API Key

```bash
# 在项目根目录创建 .env 文件
echo "VITE_OPENAI_API_KEY=sk-your-api-key" > .env
```

### 2️⃣ 启动开发服务器

```bash
npm run dev
```

### 3️⃣ 使用功能

1. 打开简历生成器页面
2. 点击 "📥 从本站获取信息" 或填写基本信息
3. 点击 "📷 上传岗位截图"
4. 选择招聘信息截图
5. 等待 AI 处理完成（15-25秒）
6. 查看生成的简历内容

## 📦 核心模块

### OCR 识别

```javascript
import { extractTextFromImage } from '@/utils/ocrParser'

const text = await extractTextFromImage(imageFile)
```

### 岗位分析

```javascript
import { analyzeJobText } from '@/ai/useJobAnalyzer'

const jobData = await analyzeJobText(text)
// 返回: { company, position, requirements, responsibilities, keywords }
```

### 简历生成

```javascript
import { generateAIResume } from '@/ai/useAIResumeGenerator'

const resume = await generateAIResume(jobTitle, resumeData, {
  model: 'openai',
  lang: 'zh',
})
// 返回: { summary, highlightedSkills, recommendations }
```

## 🐛 常见问题

### ❌ 识别失败

**原因：**

- 图片不清晰
- 没有招聘信息
- 格式不支持

**解决：**

```
✅ 使用高清截图（> 800x600）
✅ 确保包含完整招聘信息
✅ 支持格式：JPG, PNG
```

### ❌ API 调用失败

**原因：**

- 未配置 API Key
- 网络连接问题
- API 额度不足

**解决：**

```bash
# 检查配置
cat .env | grep VITE_OPENAI_API_KEY

# 测试网络
ping api.openai.com

# 查看 API 额度
# 访问: https://platform.openai.com/usage
```

### ❌ 处理时间过长

**正常范围：** 15-30 秒

**如果超过 60 秒：**

```
1. 检查网络连接
2. 查看控制台错误
3. 刷新页面重试
```
