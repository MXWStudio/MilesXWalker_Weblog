```bash
npm run dev
# 访问: http://localhost:5173/resume-generator
```

## ✨ v2.1 新功能：AI 岗位定制

### 使用步骤

1. **输入岗位** 或 **点击快捷按钮**
2. **点击 "🚀 AI 优化简历"**
3. **查看优化建议**
4. **在编辑器中应用建议**

### 快捷岗位

| 岗位名称   | 适用场景             |
| ---------- | -------------------- |
| 前端开发   | Web 开发、前端工程师 |
| UI设计师   | 界面设计、用户体验   |
| 产品经理   | 产品规划、项目管理   |
| 数据分析师 | 数据处理、商业分析   |
| 摄影师     | 摄影、视觉创作       |
| 视频剪辑   | 视频制作、后期处理   |

## 🎯 主要功能

| 功能      | 快捷键/操作   | 说明               |
| --------- | ------------- | ------------------ |
| AI 优化   | Enter         | 输入岗位后按 Enter |
| 导入简历  | 点击 📥       | 支持 MD/URL/JSON   |
| 导出 JSON | 点击 💾       | 下载简历数据       |
| 导出 PDF  | 预览区点击 📄 | 生成 PDF 文件      |
| 自动保存  | 自动          | 实时保存到本地     |

## 💡 使用技巧

### 技巧 1：多岗位对比

1. 输入岗位 A → 查看建议
2. 输入岗位 B → 对比建议差异
3. 选择最合适的优化方向

### 技巧 2：渐进式优化

1. 先完成基本信息填写
2. 使用 AI 获取优化方向
3. 逐步完善各个部分
4. 定期导出备份

### 技巧 3：快速切换岗位

1. 保存当前简历（导出 JSON）
2. 更换目标岗位
3. 根据新建议调整内容
4. 保存为不同版本

## ⚡ 常用操作流程

### 从零创建简历

```
点击快捷岗位
  ↓
查看 AI 建议
  ↓
填写基本信息
  ↓
添加工作经历
  ↓
补充技能和项目
  ↓
导出 PDF
```

### 优化现有简历

```
导入简历数据
  ↓
输入新岗位
  ↓
AI 优化建议
  ↓
调整内容重点
  ↓
预览效果
  ↓
导出新版本
```

## 🐛 快速排查

| 问题       | 检查项       | 解决方案       |
| ---------- | ------------ | -------------- |

### localStorage 键名

- `resume-last-saved`: 最后保存时间
- `resume-template`: 选择的模板
- `resume-theme-color`: 主题颜色
