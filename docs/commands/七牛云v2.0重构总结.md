## 🎯 核心改进

### 1. 安全性 🔐

**Before (v1.0):**

```javascript
// ❌ 前端暴露密钥（危险！）
this.secretKey = import.meta.env.QINIU_SECRET_KEY
```

**After (v2.0):**

```javascript
// ✅ 服务端安全管理
// server/utils/qiniu-helper.js
this.secretKey = process.env.QINIU_SECRET_KEY // 仅服务端可访问
this.mac = new qiniu.auth.digest.Mac(this.accessKey, this.secretKey)
```

### 2. 大文件上传 📦

**Before (v1.0):**

```javascript
// ❌ 只支持小文件
await qiniuService.uploadFile(file)
```

**After (v2.0):**

```javascript
// ✅ 智能上传（自动判断）
import { smartUpload } from '@/utils/qiniuUploader'

await smartUpload(file, {
  threshold: 10 * 1024 * 1024, // 10MB 自动切换
  enableResume: true, // 断点续传
  onProgress: ({ progress, uploadedChunks, totalChunks }) => {
    console.log(`${progress}% (${uploadedChunks}/${totalChunks} 分片)`)
  },
})
```

## 🚀 快速开始

### 1. 配置环境变量

编辑 `.env` 文件：

```bash
# 七牛云配置（服务端）
QINIU_ACCESS_KEY=your_access_key_here
QINIU_SECRET_KEY=your_secret_key_here
QINIU_BUCKET=your_bucket_name
QINIU_ZONE=z0

# 七牛云配置（前端）
VITE_QINIU_DOMAIN=https://cdn.example.com
VITE_API_URL=http://localhost:3000
VITE_ENABLE_QINIU_DEBUG=true
```

### 2. 启动服务

```bash
# 并发启动前后端
npm run start:dev
```

### 3. 验证功能

```bash
# 测试服务端健康
curl http://localhost:3000/api/qiniu/health

# 测试连接
curl http://localhost:3000/api/qiniu/test
```

### 4. 开始使用

```javascript
import qiniuService from '@/services/qiniuService'
import { smartUpload } from '@/utils/qiniuUploader'

// 小文件上传
await qiniuService.uploadFile(file)

// 大文件上传
await smartUpload(largeFile, { enableResume: true })
```
