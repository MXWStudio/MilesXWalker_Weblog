# Gemini 2.5 快速测试指南

## 🎯 测试目标

验证 Gemini 2.5 Flash 和 Pro 模型是否正常工作

## ✅ 配置检查

### 1. 确认 .env 配置

在项目根目录的 `.env` 文件中应该有：

```bash
VITE_GEMINI_API_KEY=你的API密钥
```

### 2. 重启开发服务器

```bash
# 停止当前服务器 (Ctrl + C)
npm run dev
```

## 🚀 快速测试步骤

### 步骤1: 检查默认模型

1. 打开简历生成器：http://localhost:8083/
2. 找到"AI 模型"选择器
3. **预期结果**：显示 **Gemini 2.5 Flash 免费** ⭐

### 步骤2: 测试 Gemini 2.5 Flash

1. **输入岗位**：`前端开发工程师`
2. **点击**：`🚀 AI 优化简历`
3. **查看控制台**（F12）：
   ```
   📡 正在调用 Google Gemini API (Gemini 2.5 Flash)...
   ✅ 简历优化完成
   ```

### 步骤3: 测试 Gemini 2.5 Pro

1. **切换模型**：
   - 点击"AI 模型"选择器
   - 选择 **Gemini 2.5 Pro**（付费模型）

2. **重新优化**：
   - 输入岗位：`高级前端架构师`
   - 点击 `🚀 AI 优化简历`

3. **查看控制台**：
   ```
   📡 正在调用 Google Gemini API (Gemini 2.5 Pro)...
   ✅ 简历优化完成
   ```

## 🔧 故障排除

### 问题1: 看不到 Gemini 2.5 模型

**解决方案**：

```bash
# 清除浏览器缓存
Ctrl + Shift + R (Windows/Linux)
Cmd + Shift + R (Mac)

# 或清除 localStorage
# 在控制台输入：
localStorage.clear()
```

### 问题2: API 调用失败

**检查 API 密钥**：

```bash
# 在浏览器控制台测试
console.log(import.meta.env.VITE_GEMINI_API_KEY)
```

**预期**：应该显示你的 API 密钥

### 问题3: 速率限制

**Gemini 免费版限制**：

- 每分钟 15 次请求
- 如果遇到限制，等待 1 分钟

**解决方案**：

- 切换到 Gemini 1.5 Flash（更高限制）
- 或升级到付费版本
