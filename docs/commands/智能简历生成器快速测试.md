## 🔧 常见问题排查

### Q1: 智能扫描失败

**可能原因：**

- 网络问题
- API Key未配置（仅影响AI分析）

**解决方案：**

```bash
# 检查API Key配置
cat .env | grep VITE_OPENAI_API_KEY

# 如果未配置，创建.env文件
echo "VITE_OPENAI_API_KEY=your_key_here" > .env
```

### Q2: 岗位匹配分析不显示

**可能原因：**

- API Key未配置
- 网络问题
- AI调用失败

**解决方案：**

- 检查浏览器控制台错误
- 确认API Key有效
- 检查网络连接

### Q3: 编辑器折叠按钮无响应

**解决方案：**

- 刷新页面
- 检查浏览器控制台错误
