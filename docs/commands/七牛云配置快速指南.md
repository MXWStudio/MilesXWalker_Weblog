# 七牛云配置快速指南

## 🎯 快速修复步骤

### 问题诊断

你遇到的 `Network Error` 是因为：

1. ❌ 缺少 `.env` 配置文件
2. ❌ 后端服务器未启动

### 解决步骤

#### 第一步：创建 `.env` 配置文件

1. **在项目根目录创建 `.env` 文件**

   ```bash
   cd "/Users/neo/Cursor project/MilesXWalker"
   touch .env
   ```

2. **复制以下配置到 `.env` 文件**（或直接重命名 `.env.setup` 为 `.env`）

```env
# 🔑 访问密钥 - 填写你的新密钥
QINIU_ACCESS_KEY=你的新AccessKey
QINIU_SECRET_KEY=你的新SecretKey

# 🪣 存储空间配置
QINIU_BUCKET=milesxwalker-resumegenerator
QINIU_REGION=cn-south-1
QINIU_ZONE=z2

# 🌐 访问域名 - 重要！必须填写
# 从七牛云获取：控制台 -> 对象存储 -> milesxwalker-resumegenerator -> 系统域名
QINIU_DOMAIN=http://milesxwalker-resumegenerator.s3.cn-south-1.qiniucs.com

# 📁 文件配置
QINIU_PATH_PREFIX=resumes/
QINIU_MAX_FILE_SIZE=10485760

# 🔐 安全配置
QINIU_PRIVATE_BUCKET=false
QINIU_EXPIRE_TIME=3600

# 前端配置
VITE_QINIU_DOMAIN=http://milesxwalker-resumegenerator.s3.cn-south-1.qiniucs.com
VITE_QINIU_BUCKET=milesxwalker-resumegenerator
VITE_QINIU_REGION=cn-south-1
VITE_QINIU_UPLOAD_URL=https://upload.qiniup.com

# 功能开关
VITE_ENABLE_QINIU=true
VITE_ENABLE_QINIU_DEBUG=true

# API 配置
VITE_API_URL=http://localhost:3000

# 应用配置
VITE_APP_TITLE=MilesXWalkerStudio
VITE_APP_VERSION=0.1.0
VITE_APP_ENV=development
```

#### 第二步：查找七牛云域名

你需要从七牛云控制台获取正确的域名：

1. **登录七牛云控制台**
   - 访问：https://portal.qiniu.com/

2. **找到存储空间**
   - 左侧菜单：`对象存储` -> `空间管理`
   - 点击空间名：`milesxwalker-resumegenerator`

3. **查看系统域名**
   - 在空间概览页面，找到 `系统域名` 或 `S3 协议域名`
   - 格式类似：`http://milesxwalker-resumegenerator.s3.cn-south-1.qiniucs.com`
   - **复制这个域名到 `.env` 文件的 `QINIU_DOMAIN` 和 `VITE_QINIU_DOMAIN`**

4. **确认存储区域**
   - 华南（广州）：`cn-south-1` / `z2`
   - 华东（浙江）：`cn-east-2` / `z1`
   - 华北（河北）：`cn-north-1` / `z0`

#### 第三步：填写密钥信息

1. **获取新的密钥**
   - 访问：https://portal.qiniu.com/user/key
   - 复制 `AccessKey` 和 `SecretKey`

2. **填写到 `.env` 文件**
   ```env
   QINIU_ACCESS_KEY=你的AccessKey
   QINIU_SECRET_KEY=你的SecretKey
   ```

#### 第四步：启动服务

你需要**同时启动**前端和后端服务：

**方式一：一键启动（推荐）**

```bash
npm run start
```

**方式二：分开启动**

终端1 - 启动后端：

```bash
npm run server
```

终端2 - 启动前端：

```bash
npm run dev
```

#### 第五步：验证配置

1. **检查后端服务**
   - 访问：http://localhost:3000/health
   - 应该看到服务器状态信息

2. **检查七牛云配置**
   - 访问：http://localhost:3000/api/qiniu/config
   - 应该看到配置信息（不包含敏感数据）

3. **测试上传功能**
   - 在简历生成器中点击"保存到云端"
   - 应该能成功上传

## 🔍 常见问题

### 问题1：QINIU_DOMAIN 应该填什么？

从你的七牛云后台截图可以看到：

- 空间名：`milesxwalker-resumegenerator`
- 存储区域：`华南-广州`（cn-south-1）
- S3 协议域名：`http(s)://milesxwalker-resumegenerator.s3.cn-south-1.qiniucs.com`

填写示例：

```env
QINIU_DOMAIN=http://milesxwalker-resumegenerator.s3.cn-south-1.qiniucs.com
VITE_QINIU_DOMAIN=http://milesxwalker-resumegenerator.s3.cn-south-1.qiniucs.com
```

### 问题2：还是提示 Network Error

确认：

1. ✅ `.env` 文件在项目根目录
2. ✅ 后端服务器已启动（`npm run server` 或 `npm run start`）
3. ✅ 能访问 http://localhost:3000/health

### 问题3：上传Token获取失败

检查：

1. ✅ AccessKey 和 SecretKey 是否正确
2. ✅ 空间名是否正确：`milesxwalker-resumegenerator`
3. ✅ 空间是否为公开空间
4. ✅ 后端控制台是否有错误信息
