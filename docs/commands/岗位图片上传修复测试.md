# 🧪 岗位图片上传修复 - 快速测试

## 问题背景

之前上传大图片时出现令牌超限错误：

```
Request too large for gpt-4o-mini: Limit 60000, Requested 77614
```

## 修复内容

✅ **图片自动压缩** - 压缩到1200px宽度，80%质量
✅ **文本智能截断** - 限制最大3000字符
✅ **保留关键信息** - 优先保留招聘信息前面部分

## 快速测试步骤

### 1. 启动开发服务器

```bash
npm run dev
```

### 2. 打开简历生成器页面

**建议测试场景：**

## 故障排查

### 问题1：仍然提示令牌超限

**可能原因：**

- 代码未正确加载
- 浏览器缓存

**解决方法：**

```bash
# 1. 停止开发服务器（Ctrl + C）
# 2. 清除缓存并重新启动
npm run dev
# 3. 硬刷新浏览器（Ctrl + Shift + R）
```

### 问题2：图片压缩失败

**检查项：**

- 图片格式是否支持（JPG/PNG）
- 文件是否损坏
- 浏览器兼容性

### 问题3：OCR识别失败

**可能原因：**

- Tesseract库未加载
- 图片质量太差

**解决方法：**

- 等待首次加载完成（约10秒）
- 使用更清晰的图片
