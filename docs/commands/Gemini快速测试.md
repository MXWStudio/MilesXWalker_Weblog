# Google Gemini 快速测试指南

## 🎯 测试目标

验证 Google Gemini API 集成是否正常工作

## ⚡ 5分钟快速配置

### 步骤1: 获取API密钥（2分钟）

1. 访问：https://aistudio.google.com/
2. 使用 Google 账户登录
3. 点击左侧 **"Get API key"**
4. 点击 **"Create API key"**
5. 复制生成的密钥

### 步骤2: 配置环境变量（1分钟）

在项目根目录创建或编辑 `.env` 文件：

```bash
# 添加 Gemini API 密钥
VITE_GEMINI_API_KEY=你的API密钥

# 示例（请替换为你的实际密钥）
VITE_GEMINI_API_KEY=AIzaSyA_ZcZ_kb2dWjxdyKKkSUk7ONEXSpmGfIE
```

⚠️ **重要**：不要把真实的 API 密钥提交到 Git！

### 步骤3: 启动项目（1分钟）

```bash
npm run dev
```

### 步骤4: 测试AI功能（1分钟）

1. **访问页面**
   - 打开：http://localhost:8083/
   - 进入简历生成器

2. **查看默认模型**
   - 找到"AI 模型"选择器
   - 应该显示：**Gemini 2.0 Flash 免费** ✅

3. **测试优化功能**
   - 输入岗位：`前端开发工程师`
   - 点击 **"🚀 AI 优化简历"**
   - 等待5-10秒

4. **查看控制台日志**
   - 打开浏览器开发者工具（F12）
   - 查看 Console 标签
   - 应该看到：
     ```
     🚀 开始全面优化简历...
     使用模型: Gemini 2.0 Flash
     📡 正在调用 Google Gemini API (Gemini 2.0 Flash)...
     ✅ 简历优化完成
     ```

## 🔧 故障排除

### 问题1: 显示"未配置 VITE_GEMINI_API_KEY"

**解决方案**：

```bash
# 1. 确认 .env 文件在项目根目录
ls -la | grep .env

# 2. 确认变量名正确（注意VITE_前缀）
cat .env

# 3. 重启开发服务器
npm run dev
```

### 问题2: API调用失败

**可能原因**：

1. API密钥无效或过期
2. 网络连接问题
3. API配额已用完

**解决方案**：

```bash
# 测试 API 密钥是否有效
curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent" \
  -H 'Content-Type: application/json' \
  -H 'x-goog-api-key: 你的API密钥' \
  -X POST \
  -d '{"contents":[{"parts":[{"text":"Hello"}]}]}'
```

### 问题3: 返回空结果或格式错误

**检查**：

- 浏览器控制台是否有错误
- Network 标签查看API响应
- 尝试切换到其他 Gemini 模型

### 问题4: 模型未显示在列表中

**解决方案**：

```bash
# 清除浏览器缓存并重新加载
Ctrl + Shift + R (Windows/Linux)
Cmd + Shift + R (Mac)
```
