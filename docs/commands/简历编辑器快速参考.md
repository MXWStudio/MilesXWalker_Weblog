# 简历编辑器快速参考

## 🚀 快速开始

### 1. 在组件中使用

```vue
<template>
  <div>
    <ResumeEditor />
    <ResumePreview />
  </div>
</template>

<script setup>
import ResumeEditor from '@/components/ResumeEditor.vue'
import ResumePreview from '@/components/ResumePreview.vue'
</script>
```

### 2. 使用 Store

```javascript
import { useResumeStore } from '@/stores/resumeStore'

const resumeStore = useResumeStore()

// 读取数据
console.log(resumeStore.resumeData)

// 修改数据
resumeStore.resumeData.fullName = '张三'
resumeStore.resumeData.targetJob = '高级前端工程师'

// 添加项目
resumeStore.addProject()

// 设置目标岗位
resumeStore.setTargetJob('全栈工程师')
```

### 3. 导出 PDF

```javascript
import { exportResumeFromStore } from '@/utils/pdfExporter'
import { useResumeStore } from '@/stores/resumeStore'

const resumeStore = useResumeStore()

// 基本导出
await exportResumeFromStore(resumeStore)

// 定制导出
await exportResumeFromStore(resumeStore, {
  fileName: '张三-高级前端工程师',
  includeTargetJob: true,
})
```

## 📋 常用操作

### 项目管理

```javascript
// 添加项目
resumeStore.addProject()

// 编辑项目
const project = resumeStore.resumeData.projects[0]
project.name = 'Vue3 电商平台'
project.technologies = ['Vue3', 'TypeScript', 'Vite']

// 删除项目
resumeStore.removeProject(projectId)
```

### 技能管理

```javascript
// 设置技能（数组）
resumeStore.resumeData.skills = ['Vue3', 'TypeScript', 'Node.js']

// 添加单个技能
resumeStore.addSkill('React')

// 删除技能
resumeStore.removeSkill('Vue3')
```

### 工作经历

```javascript
// 添加工作经历
resumeStore.addExperience()

// 删除工作经历
resumeStore.removeExperience(expId)
```

### 教育背景

```javascript
// 添加教育背景
resumeStore.addEducation()

// 删除教育背景
resumeStore.removeEducation(eduId)
```

// 导出 JSON

## 📄 数据结构

```javascript
{
  fullName: '',

  email: '',
  phone: '',

  summary: '',

  experience: [{ id, company, position, startDate, endDate, description }],
  education: [{ id, school, degree, field, startDate, endDate, gpa }],

  skills: [],
}
```

## 📝 最佳实践

1. **文件命名**: 使用 `姓名-岗位-日期` 格式
2. **定期备份**: 定期导出 JSON 备份
3. **技能列表**: 只列核心技能，不要太多
4. **项目描述**: 突出个人贡献，使用量化数据
5. **目标岗位**: 填写真实意向岗位，便于 AI 优化
