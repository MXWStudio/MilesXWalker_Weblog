# AI简历优化快速参考

> ⚡ 1分钟掌握AI简历优化核心功能

## 🚀 3步快速使用

### 1️⃣ 获取个人信息

```
点击 "🔍 智能扫描网站" → 自动填充所有信息
```

### 2️⃣ 选择优化模式

```
⚡ 快速优化：简介+技能（10-15秒）
🔍 深度优化：全面优化（20-30秒）✨ 推荐
```

### 3️⃣ 输入岗位并优化

```
方式1：手动输入 "前端开发工程师"
方式2：上传招聘截图 📷
点击 "🚀 AI 优化简历"
```

## 📊 优化结果说明

### 匹配度评分

- **80-100分** 🎉 高度匹配，竞争力强
- **60-79分** ✅ 基本匹配，有竞争力
- **40-59分** ⚠️ 部分匹配，需要提升
- **0-39分** ❌ 匹配度低，建议调整

### 优化内容

- ✨ 个人简介：针对岗位定制
- 💡 技能列表：相关技能优先
- 📝 工作经历：突出成果和数据（深度优化）
- 🚀 项目经验：强化技术栈（深度优化）

## 🎯 使用技巧

### 技巧1：选择合适模式

```
新手/简单岗位 → 快速优化
重要岗位/转型 → 深度优化
```

### 技巧2：提供详细岗位信息

```
✅ 好：上传完整的招聘截图
✅ 好：复制完整的岗位JD
❌ 差：只输入岗位名称
```

### 技巧3：优化后手动调整

```
1. 检查事实准确性
2. 添加个人特色
3. 优化数据表达
4. 调整排版格式
```

## ⚙️ 环境配置

### OpenAI API（推荐）

```bash
# 1. 创建 .env 文件
VITE_OPENAI_API_KEY=sk-your-api-key

# 2. 重启服务
npm run dev
```

### Ollama 本地（可选）

```bash
# 安装并运行
brew install ollama
ollama pull llama3.2
ollama serve
```

## 🐛 快速排查

### 问题1：API Key 错误

```bash
# 检查配置
cat .env | grep VITE_OPENAI_API_KEY
# 重启服务
npm run dev
```

### 问题2：截图识别不准

```
解决：
1. 使用高分辨率截图
2. 确保文字清晰
3. 改用手动输入
```

### 问题3：优化结果不满意

```
改进：
1. 使用深度优化模式
2. 完善个人信息
3. 提供详细岗位信息
4. 手动调整内容
```
