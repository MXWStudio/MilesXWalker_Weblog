# AI模型切换功能快速测试

## 🎯 测试目标

验证AI模型切换功能是否正常工作

## ✅ 测试步骤

### 1. 访问简历生成器

```bash
npm run dev
```

访问：http://localhost:8083/

### 2. 查看默认模型

- 打开简历生成器
- 找到"AI 模型"选择器
- 确认默认显示：**GPT-4o Mini 免费**

### 3. 测试模型切换

1. **点击模型选择按钮**
   - 应该弹出模型下拉菜单
   - 显示3个分组：免费模型、付费模型、本地模型

2. **查看模型信息**
   - 每个模型显示名称、描述、特性、定价
   - GPT-4o Mini 标记为"推荐"
   - 当前选中的模型高亮显示

3. **切换到其他模型**
   - 选择 **GPT-3.5 Turbo**
   - 下拉菜单自动关闭
   - 按钮显示更新为 "GPT-3.5 Turbo 付费"
   - 浏览器控制台输出：`✅ 已切换到模型: GPT-3.5 Turbo`

4. **刷新页面验证持久化**
   - 刷新页面
   - 模型选择器仍然显示 "GPT-3.5 Turbo"
   - 说明模型偏好已保存到 localStorage

### 4. 测试AI优化功能

1. **输入岗位信息**

   ```
   前端开发工程师
   ```

2. **选择优化模式**
   - 选择"⚡ 快速优化"或"🔍 深度优化"

3. **点击"🚀 AI 优化简历"**
   - 控制台应显示：
     ```
     🚀 开始全面优化简历...
     使用模型: GPT-3.5 Turbo (或你选择的模型名称)
     ```

4. **验证优化结果**
   - AI成功返回优化结果
   - 打开优化迭代器查看详细内容

### 5. 测试速率限制错误处理

如果遇到速率限制错误：

1. **错误提示应该显示**：

   ```
   OpenAI API 调用失败: Rate limit reached...

   💡 建议：
   1. 等待一段时间后重试
   2. 切换到付费模型（更高速率限制）
   3. 使用本地模型（无限制）
   ```

2. **切换到付费模型重试**
   - 选择 GPT-4o 或其他付费模型
   - 重新执行优化

3. **（可选）使用本地模型**
   - 如果已安装 Ollama
   - 选择 Llama 3.2
   - 应该可以正常工作（无速率限制）

### ❌ 常见问题

#### 问题1：下拉菜单不显示

- **原因**：样式未加载
- **解决**：检查 CSS 是否正确编译

#### 问题2：切换模型后仍使用旧模型

- **原因**：未正确传递参数
- **解决**：检查 `handleAIOptimize` 函数中 `selectedModel.value` 是否正确传递

#### 问题3：刷新后模型重置

- **原因**：localStorage 保存失败
- **解决**：检查浏览器是否允许 localStorage
