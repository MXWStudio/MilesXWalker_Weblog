### 4. 测试文件上传

#### 小文件上传

```javascript
import qiniuService from '@/services/qiniuService'

// 在文件输入框中选择一个小于10MB的文件
const fileInput = document.querySelector('input[type="file"]')
const file = fileInput.files[0]

const result = await qiniuService.uploadFile(file, {
  onProgress: progress => {
    console.log(`上传进度: ${progress}%`)
  },
})

console.log('上传结果:', result)
```

**预期输出：**

```javascript
{
  success: true,
  key: "uploads/1234567890_abc123.jpg",
  hash: "FmDZwqadA4-eke...",
  url: "https://cdn.example.com/uploads/1234567890_abc123.jpg",
  size: 123456,
  mimeType: "image/jpeg"
}
```

#### 大文件上传（分片）

```javascript
import { uploadLargeFile } from '@/utils/qiniuUploader'

// 选择一个大于10MB的文件
const fileInput = document.querySelector('input[type="file"]')
const file = fileInput.files[0]

const result = await uploadLargeFile(file, {
  enableResume: true,
  onProgress: ({ progress, uploadedChunks, totalChunks }) => {
    console.log(`总进度: ${progress}%`)
    console.log(`已上传: ${uploadedChunks}/${totalChunks} 分片`)
  },
  onChunkComplete: info => {
    console.log('分片完成:', info)
  },
})

console.log('大文件上传结果:', result)
```

#### 智能上传

```javascript
import { smartUpload } from '@/utils/qiniuUploader'

// 自动判断使用普通上传还是分片上传
const result = await smartUpload(file, {
  threshold: 10 * 1024 * 1024, // 10MB阈值
  onProgress: ({ progress }) => {
    console.log(`上传进度: ${progress}%`)
  },
})

console.log('智能上传结果:', result)
```

## 🐛 常见测试问题

### 问题1：服务端连接失败

```javascript
// 错误: ERR_CONNECTION_REFUSED
```

**解决：** 确保服务器已启动

```bash
npm run server
```

### 问题2：上传凭证获取失败

```javascript
// 错误: 生成上传凭证失败
```

**解决：** 检查环境变量配置

```bash
cat .env | grep QINIU
```

### 问题3：CORS 错误

```javascript
// 错误: CORS policy blocked
```

**解决：** 检查 `server/index.js` 的 CORS 配置

### 问题4：文件上传到七牛云失败

```javascript
// 错误: 401 Unauthorized
```

**解决：** 检查七牛云密钥是否正确

### 问题5：分片上传失败

```javascript
// 错误: Chunk upload failed
```

**解决：**

- 检查网络连接
- 降低分片大小
- 增加重试次数

## 📊 性能测试

### 上传速度测试

```javascript
// 测试小文件上传速度
const testSmallFile = async () => {
  const file = new File([new Array(1024 * 1024).join('a')], 'test-1mb.txt')
  const startTime = Date.now()

  const result = await qiniuService.uploadFile(file)

  const elapsed = Date.now() - startTime
  console.log(`1MB文件上传耗时: ${elapsed}ms`)
}

// 测试大文件上传速度
const testLargeFile = async () => {
  const file = new File([new Array(50 * 1024 * 1024).join('a')], 'test-50mb.txt')
  const startTime = Date.now()

  const result = await uploadLargeFile(file, {
    onProgress: ({ progress }) => {
      console.log(`${progress}%`)
    },
  })

  const elapsed = Date.now() - startTime
  console.log(`50MB文件上传耗时: ${elapsed}ms`)
  console.log(`平均速度: ${((50 * 1024) / (elapsed / 1000)).toFixed(2)}KB/s`)
}

await testSmallFile()
await testLargeFile()
```
