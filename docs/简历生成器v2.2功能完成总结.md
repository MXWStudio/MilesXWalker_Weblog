## 🎯 实现内容

### 1. 个人网站信息抓取功能

#### 位置

`src/components/ResumeGenerator.vue` - AI 智能生成区域

#### 实现细节

**UI 组件**:

```vue
<!-- 第一步：导入个人信息 -->
<div class="ai-section">
  <h3 class="section-label">📍 第一步：导入个人信息</h3>
  <div class="ai-input-group">
    <input v-model="websiteURL" />
    <button @click="handleFetchPersonalInfo">
      📥 抓取信息
    </button>
  </div>
</div>
```

**核心功能**:

- 输入个人网站 URL
- 点击"📥 抓取信息"按钮
- 自动调用 `fetchAndParseBlog()` 函数
- 解析网站内容（支持 Markdown frontmatter）
- 自动填充简历数据：
  - ✅ 基本信息（姓名、职位、邮箱、电话、地址、网站）
  - ✅ 个人简介
  - ✅ 工作经历
  - ✅ 教育背景
  - ✅ 技能列表
  - ✅ 项目经验

**用户体验**:

- 加载动画（绿色 spinner）
- 成功提示（✅ 成功抓取个人信息！）
- 引导下一步操作
- 8秒后自动隐藏提示

### 2. 基本信息折叠功能

#### 位置

`src/components/ResumeEditor.vue` - 基本信息卡片

#### 实现细节

**UI 结构**:

```vue
<div class="editor-card">
  <div class="card-header">
    <h2 class="card-title">基本信息</h2>
    <button class="btn-toggle" @click="toggleBasicInfo">
      {{ showBasicInfo ? '🔼 折叠' : '🔽 展开' }}
    </button>
  </div>

  <div v-show="showBasicInfo" class="collapsible-content">
    <!-- 基本信息表单 -->
  </div>
</div>
```

**核心功能**:

- 默认状态：折叠（`showBasicInfo = false`）
- 点击按钮切换展开/折叠
- 展开时显示所有基本信息字段
- 折叠时仅显示标题栏

**视觉效果**:

- 展开动画：从上方滑入 + 淡入（0.3秒）
- 按钮样式：紫色背景，悬停效果
- 清晰的状态图标：🔽 展开 / 🔼 折叠

### 3. AI 岗位定制功能（保留并优化）

## 💡 亮点功能

### 1. 智能两步流程

将复杂的简历创建流程简化为两步：

1. 📍 导入个人信息（自动化）
2. 🎯 选择岗位优化（智能化）

### 2. 无缝数据流转

```
个人网站
  ↓ (自动抓取)
简历数据 Store
  ↓ (自动填充)
编辑器（折叠状态）
  ↓ (AI 优化)
目标岗位定制
  ↓ (导出)
PDF 文件
```

### 3. 渐进式交互

- 默认隐藏细节（折叠）
