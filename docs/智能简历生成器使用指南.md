# 智能简历生成器使用指南

## 🎯 功能概述

全新升级的智能简历生成器能够：

- ✨ **智能扫描网站** - 自动从你的所有页面提取个人信息、技能、项目经验
- 🤖 **AI能力评估** - 深度分析你具备的技能和优势
- 📊 **岗位匹配分析** - 对比岗位要求，显示匹配度和缺失技能
- 💡 **学习路径规划** - 提供针对性的学习建议和改进方案
- 📝 **一键生成简历** - 根据目标岗位自动生成定制化简历

## 🚀 快速开始

### 第一步：智能扫描网站

1. 点击 **"🔍 智能扫描网站"** 按钮
2. 系统会自动扫描：
   - About 页面的个人信息和联系方式
   - Blog 页面的项目和作品经验
   - Portfolio 页面的作品集和技能
3. AI会深度分析你的能力画像，包括：
   - 核心竞争力
   - 推荐职业方向
   - 技能评级
   - 发展潜力

**扫描结果示例：**

```
✅ 智能扫描完成！

📊 扫描结果:
   • 提取了 25 项技能
   • 识别了 3 个项目
   • 分析了 4 个专业领域

🤖 AI深度分析:
   • 核心竞争力: 摄影创作, 前端开发, 跨学科整合
   • 推荐职业: 前端开发工程师, 产品设计师, 内容创作者
```

### 第二步：输入目标岗位

有两种方式：

**方式一：手动输入**

- 在输入框输入岗位名称，如"前端开发工程师"
- 点击 **"🚀 AI 优化简历"** 按钮

**方式二：上传岗位截图**

- 点击 **"📷 上传岗位截图"** 按钮
- 选择招聘信息的截图（支持 JPG、PNG）
- AI会自动识别岗位要求并生成匹配简历

### 第三步：查看匹配分析

AI优化完成后，会自动显示 **岗位匹配分析报告**，包含：

#### 📊 匹配度评分

- 高度匹配（80-100分）🎉
- 中度匹配（60-79分）👍
- 匹配度较低（0-59分）💪

#### ✅ 符合要求的技能

显示你已具备且岗位需要的技能，例如：

- Vue.js - 你的水平：熟练 | 岗位要求：中级
- JavaScript - 你的水平：精通 | 岗位要求：熟练

#### 💪 你的竞争优势

AI分析出的独特优势，例如：

1. **跨学科背景** - 同时具备摄影、编程和3D建模能力
2. **独立项目经验** - 能够独立完成完整项目开发
3. **用户体验意识** - 注重视觉呈现和交互体验

#### ❌ 待提升的技能

按重要性分类：

**🚨 必须掌握**

- TypeScript (技术技能) - 预计学习时间：2-4周
  - 推荐资源：TypeScript官方文档, TypeScript深入理解

**⚠️ 建议掌握**

- 单元测试 (技术技能) - 预计学习时间：2-3周

**⭐ 加分项**

- CI/CD, Docker, 微前端架构

#### 🎯 学习路径规划

**🚀 立即行动（本周开始）**

- 学习TypeScript基础语法
- 熟悉Vue 3 + TypeScript组合

**📚 短期目标（1-3个月）**

- 掌握单元测试（Jest/Vitest）
- 学习前端性能优化

**🎯 长期规划（3-6个月）**

- 深入React生态
- 学习微前端架构

#### 📝 简历优化建议

按优先级排序的具体建议：

🔴 **高优先级**

- **项目经验** - 突出使用Vue.js开发的具体项目，量化成果

🟡 **中优先级**

- **技能列表** - 将JavaScript、Vue.js放在前面，调整顺序

🟢 **低优先级**

- **个人简介** - 可以增加对前端性能优化的关注

### 第四步：下载和应用

1. **📥 下载完整报告**
   - 点击"下载完整报告"按钮
   - 获得Markdown格式的完整分析报告
   - 可用于长期学习规划

2. **✨ 应用优化建议**
   - 点击"应用优化建议"按钮
   - 自动调整简历内容和排版

3. **✏️ 手动修正**
   - 点击左侧的"✏️ 展开编辑器修正"按钮
   - 在编辑器中手动调整细节
   - 修改完成后点击"👈 收起编辑器"

## 💡 使用技巧

### 1. 定期刷新扫描

如果你更新了博客、添加了新项目，记得点击"🔄 刷新"按钮重新扫描。

### 2. 针对不同岗位优化

你可以多次使用AI优化功能，为不同的目标岗位生成定制化简历：

- 前端开发 → 突出编程技能
- 产品设计 → 突出设计和用户体验
- 内容创作 → 突出摄影和创作能力

### 3. 保存多个版本

使用"💾 导出 JSON"功能保存不同版本的简历：

- `resume_frontend_2025.json`
- `resume_designer_2025.json`
- `resume_photographer_2025.json`

### 4. 结合岗位截图

对于特定的招聘岗位，直接上传截图更精准：

- 自动识别岗位要求
- 匹配度分析更准确
- 简历针对性更强

## 🔧 常见问题

### Q1: 智能扫描需要多长时间？

A: 通常5-10秒。如果配置了OpenAI API，还会进行深度AI分析，可能需要额外5-10秒。

### Q2: 匹配度分析准确吗？

A: AI基于GPT-4o-mini模型，结合行业知识和岗位要求分析。准确度约85-90%，建议作为参考。

### Q3: 如何提高匹配度？

A:

1. 查看"待提升的技能"部分
2. 优先学习"必须掌握"的技能
3. 完成项目实践并更新到网站
4. 重新扫描和优化

### Q4: 左侧编辑器收起后如何恢复？

A: 点击左侧的"✏️ 展开编辑器修正"按钮即可展开。

### Q5: 没有配置OpenAI API怎么办？

A:

- 智能扫描仍会工作，但不会有AI深度分析
- 岗位匹配分析需要API Key
- 建议配置API以获得完整功能

## 📋 数据隐私

- 所有扫描的数据仅存储在本地浏览器
- AI分析通过OpenAI API进行，遵循其隐私政策
- 不会上传或存储你的个人信息到我们的服务器
- 可随时清空本地数据
