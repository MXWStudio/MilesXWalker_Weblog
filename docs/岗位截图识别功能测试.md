## 常见问题排查

### 问题 1: OCR 识别时间过长

**可能原因：**

- 图片文件太大
- Tesseract 首次加载需要下载模型

**解决方法：**

- 压缩图片（建议 < 1MB）
- 等待模型下载完成（首次使用）

### 问题 2: AI 分析返回空结果

**可能原因：**

- OpenAI API 调用失败
- 识别的文本不包含岗位信息

**解决方法：**

- 检查网络连接
- 检查 API Key 是否有效
- 使用更清晰的招聘信息截图

### 问题 3: 简历内容未更新

**可能原因：**

- 用户取消了替换确认
- Store 更新失败

**解决方法：**

- 点击确认对话框
- 检查浏览器控制台错误
- 刷新页面重试
