# AI 简历优化功能使用指南

## 🎯 功能概述

AI 简历优化功能可以根据您的目标岗位，智能生成个性化的简历内容，包括：

- ✨ **个性化简介**：针对目标岗位量身定制的个人简介
- 💡 **技能推荐**：突出与岗位最相关的 3-5 个技能
- 📋 **优化建议**：提供 3-5 条针对性的改进建议

## 🚀 使用步骤

### 第一步：导入个人信息

有三种方式导入您的个人信息：

#### 方式 1：从本站获取信息（推荐）

1. 点击 **"📥 从本站获取信息"** 按钮
2. 系统会自动抓取当前网站的个人信息
3. 包括基本信息、工作经历、项目经验等

#### 方式 2：手动填写

直接在简历编辑器中填写您的个人信息

#### 方式 3：导入文件

1. 点击 **"📥 导入简历"** 按钮
2. 选择 Markdown 文件、URL 或 JSON 数据
3. 系统会自动解析并填充信息

### 第二步：选择目标岗位

1. 在 **"🎯 第二步：选择目标岗位"** 输入框中输入目标岗位
   - 例如：前端开发工程师 / 摄影师 / UI设计师 / 数据分析师
2. 或者点击快捷选择按钮：
   - 前端开发
   - UI设计师
   - 产品经理
   - 数据分析师
   - 摄影师
   - 视频剪辑

### 第三步：AI 优化简历

1. 输入或选择目标岗位后，点击 **"🚀 AI 优化简历"** 按钮
2. 等待 AI 分析和生成（通常需要 5-15 秒）
3. 查看 AI 生成的结果

## 📊 AI 输出结果

AI 会返回以下内容：

```json
{
  "summary": "针对岗位的个性化简介，突出相关经验和优势",

  "recommendations": ["建议1：具体的改进建议", "建议2：突出亮点的方法", "建议3：优化建议"]
```

## 🎨 界面交互

### 个人简介处理

- 如果您的简历中**没有简介**，AI 会自动填充生成的简介
- 如果**已有简介**，系统会询问是否替换
- 您可以选择保留原有简介或使用 AI 生成的新简介

### 技能推荐处理

- AI 会检测您现有的技能列表
- 只推荐您还**没有添加**的相关技能
- 系统会询问是否添加这些新技能
- 您可以选择性地添加或跳过

### 优化建议显示

- AI 优化完成后，会在界面上显示详细的优化建议
- 建议会自动在 10 秒后隐藏
- 所有信息都会在浏览器控制台输出，方便查看

## 🔧 配置要求

### OpenAI 模式（默认）

1. 在项目根目录创建 `.env` 文件
2. 添加以下内容：
   ```
   VITE_OPENAI_API_KEY=your_openai_api_key_here
   ```
3. 重启开发服务器

### Ollama 模式（本地）

1. 安装并启动 Ollama
2. 确保已安装模型：`ollama pull llama3.2`
3. 修改代码中的模型配置：
   ```javascript
   const aiResult = await generateSmartResume(jobInput.value, resumeStore.resumeData, {
     model: 'ollama', // 改为 ollama
   })
   ```

## 🐛 常见问题

### 1. 提示"未配置 OpenAI API Key"

**解决方法**：

- 确保在项目根目录有 `.env` 文件
- 检查文件中是否有 `VITE_OPENAI_API_KEY=...`
- 重启开发服务器（`npm run dev`）

### 2. 提示"Ollama 服务未启动"

**解决方法**：

- 确保 Ollama 已安装并运行
- 检查模型是否已下载：`ollama list`
- 确保服务运行在 `http://localhost:11434`

### 3. AI 优化失败或超时

**解决方法**：

- 检查网络连接
- 确认 API Key 是否有效
- 查看浏览器控制台的详细错误信息
- 尝试减少简历数据的大小

### 4. AI 返回的内容不准确

**解决方法**：

- 确保输入的岗位描述清晰准确
- 完善您的个人信息（越详细越准确）
- 可以多次运行 AI 优化，选择最满意的结果

## 💡 使用技巧

1. **完善个人信息**：信息越详细，AI 生成的内容越准确
2. **明确岗位描述**：输入具体的岗位名称，如"高级前端开发工程师"而不是"开发"
3. **多次优化**：可以针对不同岗位多次运行，生成不同版本的简历
4. **手动调整**：AI 生成的内容可以作为参考，根据实际情况手动调整
5. **查看控制台**：打开浏览器开发者工具，可以看到详细的 AI 输出日志

## 🔐 隐私说明

- 您的简历数据只会发送到您配置的 AI 服务（OpenAI 或本地 Ollama）
- 使用 Ollama 本地模式时，数据完全在本地处理，不会上传到云端
- 建议在使用前仔细阅读相关 AI 服务的隐私政策
