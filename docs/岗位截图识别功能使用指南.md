# 📸 岗位截图识别功能使用指南

## 功能简介

这是一个智能简历生成功能，可以通过上传招聘岗位的截图，自动识别岗位信息并生成匹配的简历内容。

## 技术实现

### 核心流程

```
用户上传截图 → OCR文字识别 → AI岗位分析 → AI简历生成 → 自动填充简历
```

### 涉及模块

1. **OCR文字识别** (`@/utils/ocrParser.js`)
   - 使用 Tesseract.js 进行图片文字识别
   - 支持中文识别 (chi_sim)

2. **AI岗位分析** (`@/ai/useJobAnalyzer.js`)
   - 调用 OpenAI GPT-4o-mini 模型
   - 提取公司、岗位、要求、职责、关键词等信息

3. **AI简历生成** (`@/ai/useAIResumeGenerator.js`)
   - 根据岗位信息生成定制化简历
   - 生成个人简介、推荐技能、优化建议

## 使用方法

### 第一步：准备个人信息

在使用岗位截图识别之前，需要先填写基本信息：

1. 点击 **"📥 从本站获取信息"** 按钮，自动获取网站上的个人信息
2. 或手动在简历编辑器中填写基本信息（姓名、邮箱等）

### 第二步：上传岗位截图

1. 在 **"🎯 第二步：选择目标岗位"** 区域
2. 点击 **"📷 上传岗位截图"** 按钮
3. 选择招聘信息的截图（支持 JPG、PNG 格式）
4. 等待 AI 自动处理（约 10-30 秒）

### 第三步：查看结果

系统会自动完成以下操作：

1. ✅ 识别岗位名称和公司信息
2. ✅ 生成针对该岗位的个人简介
3. ✅ 推荐并添加相关技能
4. ✅ 提供简历优化建议
5. ✅ 设置目标岗位

## 最佳实践

### 截图质量要求

为了获得最佳识别效果，请确保：

✅ **推荐做法：**

- 图片清晰，文字可辨认
- 包含完整的招聘信息（公司、岗位、要求等）
- 光线充足，无明显阴影
- 分辨率至少 800x600 像素
- 使用截图工具而非拍照

❌ **避免：**

- 模糊不清的图片
- 过度曝光或过暗
- 文字被遮挡或截断
- 倾斜角度过大

### 支持的招聘信息格式

- 招聘网站截图（BOSS直聘、智联招聘、猎聘等）
- 公司官网招聘页面
- 微信公众号招聘推送
- PDF招聘文档截图
- 企业微信/钉钉招聘消息

## 常见问题

### Q1: 识别速度较慢？

**A:** OCR 和 AI 分析需要时间，通常 10-30 秒：

- OCR 识别：5-10 秒
- AI 岗位分析：5-10 秒
- AI 简历生成：5-10 秒

### Q2: 识别准确率如何？

**A:** 准确率取决于：

- 图片质量（清晰度最重要）
- 招聘信息完整性
- AI 模型能力（使用 GPT-4o-mini）

### Q3: 支持英文招聘吗？

**A:** 目前主要优化中文识别，英文支持正在开发中。

### Q4: 识别失败怎么办？

**A:** 可以尝试：

1. 重新截图，确保清晰度
2. 手动输入岗位名称进行 AI 优化
3. 直接编辑简历内容

### Q5: 会覆盖现有简历吗？

**A:** 不会直接覆盖，系统会：

- 弹窗询问是否替换个人简介
- 自动过滤已存在的技能
- 保留所有原始数据

### Q6: 提示"Request too large"令牌超限错误？

**A:** 已自动优化处理：

- ✅ **图片自动压缩** - 上传时自动压缩到合适大小（1200px宽度）
- ✅ **文本智能截断** - 识别的文本超过3000字符会自动截取关键部分
- ✅ **保留关键信息** - 优先保留招聘信息前面的核心内容

如果仍然遇到问题：

1. 尝试使用更小的截图区域
2. 只截取包含岗位核心信息的部分
3. 避免截取整个页面

## 代码示例

### 完整使用流程

```javascript
// 1. 导入必要模块
import { extractTextFromImage } from '@/utils/ocrParser'
import { analyzeJobText } from '@/ai/useJobAnalyzer'
import { generateAIResume } from '@/ai/useAIResumeGenerator'

// 2. 处理图片上传
const handleJobImageUpload = async event => {
  const file = event.target.files[0]
  if (!file) return

  try {
    // 步骤 1: OCR 识别
    const jobText = await extractTextFromImage(file)

    // 步骤 2: 分析岗位
    const jobData = await analyzeJobText(jobText)

    // 步骤 3: 生成简历
    const aiResume = await generateAIResume(jobData.position, resumeStore.resumeData, {
      model: 'openai',
      lang: 'zh',
    })

    // 步骤 4: 应用到简历
    resumeStore.importJSON(aiResume)

    alert(`已为岗位 "${jobData.position}" 生成简历`)
  } catch (error) {
    console.error('处理失败:', error)
    alert(error.message)
  }
}
```
