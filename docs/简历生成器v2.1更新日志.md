## ✨ 新增功能

### 🤖 AI 岗位定制功能区

在简历生成器主页面新增了智能岗位定制功能，为用户提供基于目标岗位的简历优化建议。

#### 功能特点

1. **岗位输入框**
   - 自由输入任意岗位名称
   - 支持 Enter 键快捷触发
   - 智能占位符提示

2. **快捷岗位选择**
   - 6个预设常见岗位
   - 一键选择并优化
   - 可自定义扩展

3. **AI 优化引擎**（当前版本：规则基础）
   - 自动设置目标岗位字段
   - 提供4条针对性优化建议
   - 模拟 AI 处理流程
   - 预留真实 AI API 接口

4. **优化结果反馈**
   - 实时显示优化建议
   - 优雅的动画效果
   - 8秒自动隐藏
   - 可视化反馈

5. **数据持久化**
   - 目标岗位自动保存
   - localStorage 同步
   - 刷新不丢失
