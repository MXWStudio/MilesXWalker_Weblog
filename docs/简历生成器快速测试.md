## 🐛 已知问题

### 正常行为（不是 Bug）

1. **v-html 警告**:
   - 这是预期的，用于渲染富文本
   - 不影响功能和安全性

2. **Stylelint 错误**:
   - 配置问题，不影响实际运行
   - 可以忽略

3. **首次加载较慢**:
   - Tiptap 需要加载编辑器资源
   - 后续使用会很流畅

## 🔍 开发者工具测试

### 查看 LocalStorage

1. 打开浏览器开发者工具（F12）
2. 进入 Application / Storage 标签
3. 展开 Local Storage
4. 查看以下键值:
   - `resume-draft`: 简历数据
   - `resume-last-saved`: 保存时间

### 查看 Pinia Store

1. 安装 Vue DevTools 扩展
2. 打开 Vue DevTools
3. 进入 Pinia 标签
4. 查看 `resume` store 的状态

### 控制台测试

```javascript
// 获取 Store 实例
const { useResumeStore } = await import('@/stores/resume')
const resumeStore = useResumeStore()

// 查看简历数据
console.log(resumeStore.resumeData)

// 查看完成度
console.log(resumeStore.completionPercentage)

// 导出 JSON
resumeStore.exportJSON()

// 重置简历
resumeStore.resetResume()
```
