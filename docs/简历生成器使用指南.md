# 📄 简历生成器使用指南

## 🎯 功能概述

MilesXWalker 简历生成器是一个功能强大的在线简历创建工具，支持富文本编辑、自动保存草稿、实时预览和专业 PDF 导出。

## 🚀 快速开始

### 访问方式

1. **直接访问**：http://localhost:5173/resume-generator
2. **从导航菜单**：点击顶部导航栏的"简历生成器"链接

### 基本流程

1. 📸 上传个人头像（可选）
2. 📝 填写基本信息（姓名、职位、联系方式）
3. ✍️ 使用富文本编辑器编写个人简介
4. 📋 添加工作经历和教育背景
5. 🎨 添加技能标签
6. 👀 实时预览简历效果
7. 📥 导出为 PDF 文件

## 💡 核心功能

### 1. 头像上传 📸

#### 功能特点

- **多格式支持**: JPG、PNG、WEBP
- **图片预览**: 实时查看上传的头像
- **简单操作**: 点击上传、一键删除
- **自动保存**: 头像数据自动保存到本地
- **PDF导出**: 头像完美呈现在导出的PDF中

#### 使用方法

**上传头像**:

1. 展开"基本信息"区域
2. 点击"上传头像"按钮
3. 选择图片文件（支持 JPG、PNG、WEBP）
4. 系统自动上传并显示预览

**更换头像**:

1. 点击"更换头像"按钮
2. 选择新的图片文件

**删除头像**:

1. 在头像预览上点击右上角的 "✕" 按钮
2. 确认删除

#### 技术说明

- **存储方式**: Base64 编码
- **文件大小限制**: 最大 5MB
- **推荐尺寸**: 400x400 像素
- **显示效果**: 圆形头像，自动裁剪适配

#### 注意事项

⚠️ **重要提示**:

- 头像会被转换为 Base64 格式存储在浏览器本地
- 图片文件过大可能影响存储和加载速度
- 建议使用清晰的正面照
- 推荐使用正方形图片以获得最佳显示效果

### 2. 富文本编辑器

#### 支持的格式

- **粗体** (`Ctrl+B` / `Cmd+B`)
- _斜体_ (`Ctrl+I` / `Cmd+I`)
- <u>下划线</u> (`Ctrl+U` / `Cmd+U`)
- 标题（H3、H4）
- 段落
- 有序列表
- 无序列表
- 清除格式

#### 使用场景

富文本编辑器在以下字段中可用：

- 个人简介
- 工作描述

#### 操作技巧

1. 选中文字后点击工具栏按钮应用格式
2. 使用快捷键提高编辑效率
3. 点击"清除格式"移除所有样式
4. 使用列表功能突出重点成就

### 2. 自动保存草稿 💾

#### 工作原理

- 使用 localStorage 本地存储
- 每次输入后自动保存
- 刷新页面不会丢失数据
- 显示上次保存时间

#### 查看保存状态

页面顶部显示"上次保存"时间：

- "刚刚" - 少于 1 分钟前
- "X 分钟前" - 少于 1 小时
- "X 小时前" - 少于 24 小时
- "X 天前" - 少于 7 天
- 完整日期 - 7 天以前

#### 清除草稿

如需重新开始：

1. 清除浏览器 localStorage
2. 或在开发者工具中删除 `resume-draft` 键

### 3. 完成度追踪 📊

#### 进度指标

页面顶部显示简历完成度百分比，基于以下字段：

**必填项** (总分 8 项):

- ✅ 姓名
- ✅ 职位
- ✅ 邮箱
- ✅ 电话
- ✅ 个人简介
- ✅ 至少一个工作经历
- ✅ 至少一个教育背景
- ✅ 至少一个技能

**可选项**:

- 📸 个人头像
- 📍 所在地址
- 🌐 个人网站

#### 如何提高完成度

1. 填写所有基本信息字段
2. 确保工作经历包含公司名称
3. 确保教育背景包含学校名称
4. 添加至少 3-5 个技能标签

### 4. PDF 导出 📥

#### 导出选项

**方式一：下载 PDF**

1. 点击"下载 PDF"按钮
2. 等待生成（通常 2-3 秒）
3. PDF 文件自动下载

**方式二：预览 PDF**

1. 点击"预览"按钮
2. 在新窗口中查看 PDF
3. 可从浏览器打印或保存

#### PDF 文件名格式

```
{姓名}-简历.pdf
例如：张三-简历.pdf
```

#### PDF 质量参数

- **纸张**: A4 (210mm × 297mm)
- **方向**: 纵向 (Portrait)
- **边距**: 10mm (上下左右)
- **图片质量**: 98% JPEG
- **缩放**: 2x（高清输出）

#### 常见问题

**Q: PDF 导出失败怎么办？**

- 确保已填写姓名
- 检查浏览器是否允许下载
- 尝试使用"预览"功能

**Q: PDF 格式不对？**

- 检查简历内容是否过长
- 尝试缩短某些描述
- 使用列表代替长段落

### 5. 数据管理 📦

#### 导出 JSON

（功能已在 Store 中实现，可扩展到 UI）

```javascript
// 在浏览器控制台中执行
const resumeStore = useResumeStore()
resumeStore.exportJSON()
```

#### 导入 JSON

```javascript
// 在浏览器控制台中执行
const resumeStore = useResumeStore()
const data = {
  /* 简历数据 */
}
resumeStore.importJSON(data)
```

#### 从 Markdown 导入

```javascript
// 在浏览器控制台中执行
const resumeStore = useResumeStore()
const markdown = `
---
name: 张三
title: 前端工程师
email: zhangsan@example.com
---

这是我的个人简介...
`
resumeStore.importFromMarkdown(markdown)
```

## 🎨 最佳实践

### 内容建议

#### 个人简介

- **长度**: 3-5 行
- **重点**: 职业定位、核心技能、职业目标
- **格式**: 使用粗体突出关键词

示例：

```
拥有5年前端开发经验的工程师，精通 Vue.js、React 和 TypeScript。
擅长构建高性能、可维护的 Web 应用。热衷于学习新技术，具有
良好的团队协作能力。
```

#### 工作经历

- **公司名称**: 全称
- **职位**: 具体职位名称
- **日期**: YYYY-MM 格式（例如：2020-01）
- **描述**:
  - 使用列表形式
  - 突出具体成就和数据
  - 使用动词开头（负责、开发、优化、提升）

示例：

```
• 负责公司核心产品前端架构设计和开发
• 优化首屏加载速度，性能提升 40%
• 带领 5 人团队完成 10+ 个项目
```

#### 教育背景

- **学校**: 全称
- **专业**: 专业名称 + 学历（例如：计算机科学与技术（本科））
- **日期**: YYYY-MM 格式
- **GPA**: 如果优秀可添加（可选）

#### 技能标签

- **数量**: 5-10 个
- **分类**: 编程语言、框架、工具、软技能
- **优先级**: 最重要的技能放在前面

示例：

```
Vue.js
JavaScript/TypeScript
React
Node.js
Git
团队协作
项目管理
```

### 排版建议

1. **保持一致性**
   - 日期格式统一
   - 标点符号统一（中文/英文）
   - 用词风格统一

2. **突出重点**
   - 使用粗体强调关键信息
   - 用列表展示成就
   - 数据量化（提升 X%、完成 X 个项目）

3. **简洁明了**
   - 避免冗长的句子
   - 删除无关紧要的信息
   - 每段工作经历 3-5 条要点

4. **视觉平衡**
   - 各部分长度适中
   - 避免某一部分过长
   - 留白适当

## 🐛 故障排除

### 常见问题

#### 1. 数据丢失

**症状**: 刷新页面后简历数据消失

**原因**:

- 浏览器隐私模式
- localStorage 被禁用
- 浏览器缓存被清除

**解决方案**:

- 使用正常模式浏览器
- 启用 localStorage
- 定期导出 JSON 备份

#### 2. 富文本编辑器无响应

**症状**: 工具栏按钮不工作

**原因**:

- JavaScript 加载失败
- 编辑器未初始化

**解决方案**:

- 刷新页面
- 检查浏览器控制台错误
- 清除浏览器缓存

#### 3. PDF 导出失败

**症状**: 点击下载按钮后无反应

**原因**:

- 姓名未填写
- 浏览器阻止下载
- 内容过长导致超时

**解决方案**:

- 确保填写姓名
- 允许浏览器下载
- 缩短简历内容
- 使用"预览"功能

#### 4. 样式显示异常

**症状**: 预览区域格式错乱

**原因**:

- CSS 加载失败
- 浏览器兼容性问题

**解决方案**:

- 刷新页面
- 使用现代浏览器（Chrome、Firefox、Edge）
- 检查网络连接
