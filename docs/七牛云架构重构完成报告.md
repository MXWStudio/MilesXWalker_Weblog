# 七牛云架构重构完成报告 v2.0

## 📋 概述

本次重构完全遵循七牛云官方 Node.js SDK 最佳实践，将前端不安全的实现方式升级为安全的服务端签名架构，显著提升了系统的安全性、可靠性和功能完整性。

## 🎯 重构目标

### 主要目标

1. **安全性提升** ✅ - 密钥不再暴露在前端
2. **功能完整** ✅ - 使用官方 SDK 的完整功能
3. **大文件支持** ✅ - 实现分片上传和断点续传
4. **性能优化** ✅ - 并发上传、智能重试
5. **架构规范** ✅ - 符合官方最佳实践

## 🔧 架构变更

### 旧架构（v1.0）⚠️

```
前端 (qiniuService.js)
  ├─ 包含 AccessKey 和 SecretKey ❌ 安全隐患！
  ├─ 前端直接生成上传凭证
  ├─ 手动实现 HMAC-SHA1 签名
  └─ 直接上传到七牛云
```

**问题：**

- ❌ SecretKey 暴露在前端代码中
- ❌ 无法使用官方 SDK 高级功能
- ❌ 不支持大文件分片上传
- ❌ 缺少服务端验证机制

### 新架构（v2.0）✅

```
前端 (qiniuService.js v2.0)
  ├─ 仅包含公开配置（域名等）✅
  ├─ 调用服务端 API 获取上传凭证
  ├─ 使用上传凭证上传到七牛云
  └─ 支持分片上传（qiniuUploader.js）

     ⬇️ HTTP API

服务端 (server/api/qiniu.js)
  ├─ 使用官方 qiniu SDK v7.14.0
  ├─ 安全的密钥管理 ✅
  ├─ 生成上传凭证（/api/qiniu/upload-token）
  ├─ 验证上传回调（/api/qiniu/callback）
  └─ 文件管理操作（增删改查）
```

**优势：**

- ✅ 密钥安全存储在服务端
- ✅ 使用官方 SDK 完整功能
- ✅ 支持大文件分片上传
- ✅ 可验证七牛云回调
- ✅ 符合官方最佳实践

## 🔐 安全性提升

### 密钥管理

**旧方式：**

```javascript
// ❌ 前端暴露密钥（不安全！）
this.accessKey = import.meta.env.QINIU_ACCESS_KEY
this.secretKey = import.meta.env.QINIU_SECRET_KEY // 危险！
```

**新方式：**

```javascript
// ✅ 服务端安全管理
// 前端只包含公开配置
this.domain = import.meta.env.VITE_QINIU_DOMAIN
this.apiBaseUrl = import.meta.env.VITE_API_URL

// 服务端（server/utils/qiniu-helper.js）
this.accessKey = process.env.QINIU_ACCESS_KEY // ✅ 服务端环境变量
this.secretKey = process.env.QINIU_SECRET_KEY // ✅ 安全！
this.mac = new qiniu.auth.digest.Mac(this.accessKey, this.secretKey)
```

### 上传流程

**新的安全上传流程：**

```
1. 前端请求上传凭证
   POST /api/qiniu/upload-token
   Body: { key, expires, fsizeLimit, mimeLimit }

2. 服务端生成凭证
   - 验证请求参数
   - 使用 SecretKey 签名（服务端）
   - 返回临时上传凭证

3. 前端使用凭证上传
   - 上传到七牛云
   - 凭证自动过期（默认 1 小时）

4. 七牛云回调（可选）
   - 回调到服务端 /api/qiniu/callback
   - 服务端验证回调签名
   - 处理业务逻辑
```

## 🐛 故障排除

### 常见问题

#### 1. 服务端连接失败

**问题：** `Network Error` 或 `ERR_CONNECTION_REFUSED`

**解决方案：**

```bash
# 检查服务器是否运行
npm run server

# 检查端口是否正确
# 默认端口: 3000
```

#### 2. 上传凭证获取失败

**问题：** `生成上传凭证失败`

**解决方案：**

```bash
# 检查环境变量
cat .env | grep QINIU

# 确保配置了必要的变量
QINIU_ACCESS_KEY=...
QINIU_SECRET_KEY=...
QINIU_BUCKET=...
VITE_QINIU_DOMAIN=...
```

#### 3. 大文件上传失败

**问题：** 分片上传失败或超时

**解决方案：**

```javascript
// 调整分片大小和重试次数
const result = await uploadLargeFile(file, {
  chunkSize: 2 * 1024 * 1024, // 降低到 2MB
  maxRetries: 5, // 增加重试次数
  debug: true, // 开启调试日志
})
```

#### 4. CORS 错误

**问题：** 跨域请求被阻止

**解决方案：**

```javascript
// 检查 server/index.js 中的 CORS 配置
const corsOptions = {
  origin: [
    'http://localhost:5173', // 添加你的前端地址
    'http://localhost:5174',
  ],
  credentials: true,
}
```
