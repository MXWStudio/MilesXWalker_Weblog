# 七牛云配置使用指南

## 📋 概述

本指南将帮助您在MilesXWalkerStudio项目中配置和使用七牛云对象存储服务，实现高效的文件上传、存储和管理功能。

## 🚀 快速开始

### 第一步：运行配置向导

```bash
# 运行七牛云配置向导
npm run setup:qiniu
```

配置向导将自动检查：

- ✅ qshell工具状态
- ✅ 账户配置
- ✅ 环境变量设置
- ✅ 存储空间连通性
- ✅ 服务可用性

### 第二步：手动配置（如需要）

如果自动配置未完成，请按以下步骤手动配置：

#### 1. 获取七牛云密钥

1. 访问 [七牛云密钥管理](https://portal.qiniu.com/user/key)
2. 复制您的 `AccessKey` 和 `SecretKey`

#### 2. 配置qshell工具

```bash
# 配置账户（替换为您的实际密钥）
"/Users/neo/Cursor project/qshell" account <AccessKey> <SecretKey> <账户名称>

# 例如：
"/Users/neo/Cursor project/qshell" account abc123 def456 myaccount
```

#### 3. 配置环境变量

编辑项目根目录的 `.env` 文件：

```bash
# 七牛云配置 - 对象存储 Kodo
# ========================================
# 🔑 访问密钥
QINIU_ACCESS_KEY=your_access_key_here
QINIU_SECRET_KEY=your_secret_key_here

# 🪣 存储空间配置
QINIU_BUCKET=your_bucket_name_here
QINIU_REGION=cn-east-1
QINIU_ZONE=z0

# 🌐 访问域名配置
QINIU_DOMAIN=your_domain_here
VITE_QINIU_DOMAIN=your_domain_here

# 📁 文件上传配置
QINIU_PATH_PREFIX=uploads/
QINIU_MAX_FILE_SIZE=10485760

# 🔐 安全配置
QINIU_PRIVATE_BUCKET=false
QINIU_EXPIRE_TIME=3600

# 功能开关
VITE_ENABLE_QINIU=true
VITE_ENABLE_QINIU_DEBUG=true
```

## 🛠 创建存储空间

### 在七牛云控制台创建

1. 访问 [七牛云对象存储](https://portal.qiniu.com/kodo/bucket)
2. 点击 "新建存储空间"
3. 填写配置：
   - **存储空间名称**：全局唯一，如 `mxw-storage`
   - **存储区域**：选择距离用户最近的区域
   - **访问控制**：
     - 公开：允许匿名访问（推荐用于图片、视频等静态资源）
     - 私有：需要授权访问（推荐用于敏感文件）

### 配置访问域名

七牛云提供两种域名方式：

#### 1. 测试域名（临时使用）

- 自动分配，30天后回收
- 格式：`xxx.clouddn.com`
- 仅用于开发测试

#### 2. 自定义域名（推荐）

1. 在存储空间设置中绑定自己的域名
2. 在域名解析商处添加CNAME记录
3. 等待DNS生效（通常几分钟到几小时）

## 🎯 功能特性

### 文件上传组件

项目提供了完整的文件上传组件 `QiniuUploader`：

```vue
<template>
  <QiniuUploader
    :accepted-types="'image/*,video/*,.pdf,.doc,.docx'"
    :max-file-size="10485760"
    :path-prefix="'uploads/'"
    @upload-success="handleUploadSuccess"
    @upload-error="handleUploadError"
    @upload-progress="handleUploadProgress"
  />
</template>
```

### 主要功能

✅ **拖拽上传**：支持拖拽文件到上传区域
✅ **进度显示**：实时显示上传进度
✅ **文件管理**：查看、删除、复制链接
✅ **批量操作**：支持多文件同时上传
✅ **错误处理**：自动重试失败的上传
✅ **类型限制**：支持文件类型和大小限制
✅ **响应式设计**：适配各种屏幕尺寸

### API服务

项目提供了完整的七牛云服务API：

```javascript
import qiniuService from '@/services/qiniuService'

// 上传文件
const result = await qiniuService.uploadFile(file, {
  pathPrefix: 'images/',
  onProgress: progress => console.log(progress),
})

// 获取文件列表
const files = await qiniuService.listFiles({
  limit: 100,
  prefix: 'uploads/',
})

// 删除文件
await qiniuService.deleteFile('uploads/image.jpg')

// 获取文件访问URL
const url = qiniuService.getFileUrl('uploads/image.jpg')
```

const putPolicy = {

## 🔍 故障排除

### 常见问题

#### 1. qshell工具找不到

```bash
# 检查qshell工具路径
ls -la "/Users/neo/Cursor project/qshell"

# 如果文件不存在，重新下载
```

#### 2. 连接测试失败

- 检查AccessKey和SecretKey是否正确
- 确认存储空间名称是否正确
- 检查网络连接

#### 3. 上传失败

- 检查文件大小是否超过限制
- 确认文件类型是否被允许
- 查看浏览器控制台错误信息

#### 4. 域名无法访问

- 检查域名是否正确配置
- 确认DNS解析是否生效
- 测试域名连通性

### 调试模式

启用调试模式查看详细日志：

```bash
VITE_ENABLE_QINIU_DEBUG=true
```

### 测试连接

```bash
# 使用qshell测试连接
"/Users/neo/Cursor project/qshell" listbucket your_bucket_name --limit 1
```
