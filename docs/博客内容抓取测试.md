```javascript
// 测试标签提取功能
const tagTests = [

    expected: ['设计'],
  },
]

for (const test of tagTests) {
  const result = await fetchBlogResumeData({
    source: 'local',
    blogPosts: [
      {
        title: test.title,
        excerpt: '',
        date: '2024-01-01',
        category: '测试',
      },
    ],
  })

  const extractedTags = result.works[0].tags
  console.log(`标题: "${test.title}"`)
  console.log(`提取的标签: ${extractedTags.join(', ')}`)
  console.log(`预期标签: ${test.expected.join(', ')}`)
  console.log('---')
}
```

## 常见问题排查

### 问题 1: 函数未定义

**错误:** `fetchBlogResumeData is not defined`

**解决:**

```javascript
// 确保正确导入
import { fetchBlogResumeData } from '@/utils/blogParser'
```

### 问题 2: 标签提取不准确

**解决:** 检查 `extractTags()` 函数中的关键词配置，添加或修改相关关键词。

### 问题 3: 日期排序错误

**检查:** 确保博客文章的 `date` 字段格式正确，如 `YYYY-MM-DD`。
