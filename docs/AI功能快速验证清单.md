### 1️⃣ 环境检查（30秒）

## ❌ 常见问题速查

### 问题 1：提示 "未配置 API Key"

```bash
# 解决：创建 .env 文件
echo "VITE_OPENAI_API_KEY=your-key-here" > .env
npm run dev  # 重启服务
```

### 问题 2：一直加载中

- 检查网络连接
- 检查 API Key 是否有效
- 查看控制台错误信息

### 问题 3：返回结果为空

- 确保已导入基本信息
- 检查岗位输入是否为空
