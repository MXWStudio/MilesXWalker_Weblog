# 博客内容抓取使用指南

## 功能概述

`blogParser.js` 中的 `fetchBlogResumeData()` 函数可以从多种数据源抓取博客内容,并自动提取个人简历相关的信息,包括姓名、爱好、作品和技能。

## 返回数据结构

```javascript
{
  name: "Miles Walker",
  hobbies: ["摄影", "编程", "设计"],
  works: [
    {
      title: "新疆风光摄影记录",
      tags: ["风景", "旅行", "胶片"],
      date: "2025-02-10",
      category: "摄影作品",
      excerpt: "记录新疆独特的自然风光..."
    },
    {
      title: "TrailLog App 开发日志",
      tags: ["Vue3", "独立开发"],
      date: "2025-06-01",
      category: "技术分享",
      excerpt: "从 FullTrack 到 Trail Log..."
    },
  ],
  skills: ["Vue3", "Lightroom", "Figma", "Ableton"],
}
```

## 使用方法

### 1. 从本地博客数据抓取（推荐）

这是最简单的方式,直接使用项目中的博客文章数据:

```javascript
import { fetchBlogResumeData } from '@/utils/blogParser'

// 在组件中使用
const blogPosts = ref([
  {
    title: '新疆风光摄影记录',
    excerpt: '记录新疆独特的自然风光和人文景观',
    date: '2025-02-10',
    category: '摄影作品',
  },
  {
    title: 'TrailLog App 开发日志',
    excerpt: '从 FullTrack 到 Trail Log：打造纯粹的徒步工具',
    date: '2025-06-01',
    category: '技术分享',
  },
])

const resumeData = await fetchBlogResumeData({
  source: 'local',
  blogPosts: blogPosts.value,
  profile: {
    name: 'Miles Walker',
    hobbies: ['摄影', '编程', '设计', '徒步'],
    skills: ['Vue3', 'Lightroom', 'Figma', 'Ableton', 'Three.js'],
  },
})

console.log(resumeData)
// {
//   name: 'Miles Walker',
//   hobbies: ['摄影', '编程', '设计', '徒步'],
//   works: [...],
//   skills: ['Vue3', 'Lightroom', 'Figma', 'Ableton', 'Three.js']
// }
```

### 2. 从 Markdown 文件抓取

如果你有一个包含完整信息的 Markdown 文件:

```javascript
import { fetchBlogResumeData } from '@/utils/blogParser'

// 处理文件上传
const handleFileUpload = async event => {
  const file = event.target.files[0]

  const resumeData = await fetchBlogResumeData({
    source: 'markdown',
    file: file,
  })

  console.log(resumeData)
}
```

**Markdown 文件格式示例:**

```markdown
---
name: Miles Walker
```

### 3. 从 API 抓取

如果你有一个博客 API 接口:

```javascript
import { fetchBlogResumeData } from '@/utils/blogParser'

const resumeData = await fetchBlogResumeData({
  source: 'api',
  apiUrl: 'https://api.example.com/blog',
})
```

**API 返回格式要求:**

## 实际应用示例

### 在简历生成器中使用

```vue
<script setup>
import { ref } from 'vue'
import { fetchBlogResumeData } from '@/utils/blogParser'
import { useResumeStore } from '@/stores/resumeStore'

const resumeStore = useResumeStore()

const importFromBlog = async () => {
  try {
    // 获取博客数据（假设从 Blog.vue 导入）
    const blogPosts = [
      // ... 博客文章数据
    ]

    const blogData = await fetchBlogResumeData({
      source: 'local',
      blogPosts: blogPosts,
      profile: {
        name: 'Miles Walker',
        hobbies: ['摄影', '编程', '设计'],
        skills: ['Vue3', 'Lightroom', 'Figma', 'Ableton'],
      },
    })

    // 更新简历 store
    resumeStore.resumeData.fullName = blogData.name
    resumeStore.resumeData.skills = blogData.skills.join(', ')

    // 将作品转换为项目经验
    blogData.works.forEach(work => {
      resumeStore.addProject({
        name: work.title,
        description: work.excerpt,
        technologies: work.tags,
        startDate: work.date,
      })
    })

    alert('成功从博客导入数据!')
  } catch (error) {
    alert('导入失败: ' + error.message)
  }
}
</script>

<template>
  <button @click="importFromBlog">从博客导入</button>
</template>
```

## 配置选项

### 默认配置

函数使用以下默认配置:

```javascript
{
  name: 'Miles Walker',
  hobbies: ['摄影', '编程', '设计', '3D建模', '徒步'],
  skills: ['Vue3', 'Lightroom', 'Figma', 'Ableton', 'Three.js', 'TypeScript'],
}
```

### 自定义配置

你可以通过 `profile` 参数覆盖默认配置:

```javascript
const resumeData = await fetchBlogResumeData({
  source: 'local',
  blogPosts: myPosts,
  profile: {
    name: '你的名字',
    hobbies: ['自定义爱好1', '自定义爱好2'],
    skills: ['自定义技能1', '自定义技能2'],
  },
})
```

## 错误处理

函数会抛出错误,建议使用 try-catch 处理:

```javascript
try {
  const data = await fetchBlogResumeData({
    source: 'api',
    apiUrl: 'https://invalid-url.com',
  })
} catch (error) {
  console.error('抓取失败:', error.message)
  // 显示错误提示
  alert('无法获取博客数据，请检查网络连接')
}
```

## 常见问题

### Q: 如何添加新的标签识别规则?

修改 `extractTags()` 函数中的 `techKeywords` 对象:

```javascript
const techKeywords = {
  Vue3: ['Vue3', 'Vue', 'vue3'],
  TypeScript: ['TypeScript', 'TS'],
  // 添加新规则
  你的标签: ['关键词1', '关键词2'],
}
```

### Q: 如何自定义作品排序?

默认按日期降序排序。如果需要自定义,修改 `fetchFromLocalData()` 函数:

```javascript
// 按标题字母顺序排序
works.sort((a, b) => a.title.localeCompare(b.title))

// 或按分类排序
works.sort((a, b) => a.category.localeCompare(b.category))
```

### Q: 如何过滤特定分类的文章?

在调用函数前过滤:

```javascript
const filteredPosts = blogPosts.filter(
  post => post.category === '摄影作品' || post.category === '技术分享'
)

const resumeData = await fetchBlogResumeData({
  source: 'local',
  blogPosts: filteredPosts,
})
```
