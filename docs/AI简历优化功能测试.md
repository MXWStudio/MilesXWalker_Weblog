### 测试 4：技能推荐处理

**步骤：**

**预期结果：**

- [ ] 点击确定后，技能自动添加到简历中

### 测试 5：简介替换处理

**前提：** 简历中已有个人简介

**步骤：**

1. 确保简历中已有简介内容
2. 选择岗位：`产品经理`
3. 点击 AI 优化
4. 当弹出简介替换对话框时

**测试 5.1 - 选择替换：**

- [ ] 点击 "确定"
- [ ] 简介被替换为 AI 生成的新简介
- [ ] 控制台显示：`✨ 已更新简介`

**测试 5.2 - 选择保留：**

- [ ] 点击 "取消"
- [ ] 原有简介保持不变
- [ ] 其他功能（技能推荐、优化建议）仍然正常工作

### 测试 7：错误处理 - 未配置 API Key

**步骤：**

1. 临时删除或注释掉 `.env` 中的 `VITE_OPENAI_API_KEY`
2. 重启开发服务器
3. 尝试 AI 优化

**预期结果：**

- [ ] 显示友好的错误提示
- [ ] 提示包含配置说明
- [ ] 控制台显示错误信息：`❌ AI 优化失败: 未配置 VITE_OPENAI_API_KEY`

---

### 测试 8：错误处理 - 无基本信息

**步骤：**

1. 清空所有简历数据（点击刷新按钮）
2. 不导入任何信息
3. 直接输入岗位并点击 AI 优化

**预期结果：**

- [ ] 显示提示：`请先填写基本信息或从本站获取个人信息后再使用 AI 优化功能`
- [ ] 不会发起 API 调用

---
