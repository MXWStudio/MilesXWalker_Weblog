### 6. PDF 导出测试

#### 测试 1: 从 DOM 元素导出

```javascript
import { exportResumePDF } from '@/utils/pdfExporter'

const element = document.querySelector('.resume-preview')
const result = await exportResumePDF(element, '测试简历')

console.log('导出结果:', result)
// 应该看到: { success: true }
```

#### 测试 2: 从 Store 直接导出

```javascript
import { exportResumeFromStore } from '@/utils/pdfExporter'
import { useResumeStore } from '@/stores/resumeStore'

const resumeStore = useResumeStore()

// 基本导出
const result1 = await exportResumeFromStore(resumeStore)
console.log('基本导出:', result1)

// 带目标岗位导出
const result2 = await exportResumeFromStore(resumeStore, {
  fileName: '张三-高级前端工程师-简历',
  includeTargetJob: true,
})
console.log('定制导出:', result2)
```

## 🐛 常见问题排查

### 问题 1: 技能列表不显示

**检查:**

```javascript
const resumeStore = useResumeStore()
console.log(resumeStore.resumeData.skills)
console.log(Array.isArray(resumeStore.resumeData.skills))
```

**解决:** 确保技能保存为数组格式

### 问题 2: PDF 导出失败

**检查:**

```javascript
// 1. 检查 html2pdf 是否已安装
import html2pdf from 'html2pdf.js'
console.log(html2pdf)

// 2. 检查 resumeData 是否完整
console.log(resumeStore.resumeData)

// 3. 查看错误详情
const result = await exportResumeFromStore(resumeStore)
if (!result.success) {
  console.error(result.error)
}
```

### 问题 3: 目标岗位不保存

**检查:**

```javascript
// 查看 localStorage
const draft = localStorage.getItem('resume-draft')
const data = JSON.parse(draft)
console.log('目标岗位:', data.targetJob)

// 检查 Store
console.log(resumeStore.resumeData.targetJob)
```

### 问题 4: 项目技术栈不显示

**检查:**

```javascript
const project = resumeStore.resumeData.projects[0]
console.log('技术栈类型:', typeof project.technologies)
console.log('技术栈内容:', project.technologies)

```
