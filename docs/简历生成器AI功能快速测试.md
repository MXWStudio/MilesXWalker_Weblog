## ❌ 常见问题排查

### 问题 1：按钮点击无反应

**可能原因**:

- 输入框为空
- 正在优化中（等待完成）

**解决方案**:

- 确保输入框有内容
- 等待当前优化完成

### 问题 2：优化结果不显示

**检查步骤**:

1. 打开浏览器控制台（F12）
2. 查看是否有 JavaScript 错误
3. 确认 `aiOptimizationResult` 状态是否更新

**解决方案**:

- 刷新页面重试
- 清除浏览器缓存

### 问题 3：目标岗位未保存

**检查步骤**:

1. 查看 localStorage
   ```javascript
   localStorage.getItem('resume-draft')
   ```
2. 确认 `targetJob` 字段

**解决方案**:

- 检查 resumeStore 中的 `setTargetJob` 方法
- 确保浏览器允许 localStorage
