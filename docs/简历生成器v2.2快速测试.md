### ✅ 测试 1：个人网站信息抓取

如果您有个人博客/网站，使用真实 URL。否则可以测试以下操作：

## ❌ 常见问题排查

### 问题 1：抓取按钮无响应

**检查**:

- URL 是否已输入？
- 按钮是否禁用状态？
- Console 中是否有错误？

**解决**:

- 确保 URL 有效
- 等待之前的抓取完成
- 刷新页面重试

### 问题 2：折叠按钮不工作

**检查**:

- 点击是否有反应？
- 按钮文字是否改变？

**解决**:

- 检查 JavaScript 是否启用
- 清除浏览器缓存
- 刷新页面

### 问题 3：数据未填充

**检查**:

- 个人网站格式是否正确？
- 网站是否包含结构化数据？
- Network 请求是否成功？

**解决**:

- 使用包含 Markdown frontmatter 的网站
- 检查网站是否可访问
- 查看 Console 错误信息
