# 简历生成器 v2.2 更新日志

## 📅 更新信息

- **版本号**: v2.2
- **更新日期**: 2025-10-09
- **更新类型**: 功能增强 + UX 优化
- **更新重点**: 个人网站信息抓取 + 基本信息折叠

## ✨ 新增功能

### 🌐 个人网站信息抓取

在 AI 智能生成区域新增"个人信息导入"功能，支持从个人网站自动抓取基本信息。

#### 功能特点

1. **URL 输入框**
   - 输入个人网站或博客地址
   - 支持 Enter 键快捷触发
   - 智能占位符提示

2. **一键抓取**
   - 自动解析网站内容
   - 提取基本信息（姓名、职位、邮箱、电话等）
   - 自动填充工作经历、教育背景、技能、项目

3. **智能提示**
   - 抓取成功后显示反馈信息
   - 提示下一步操作（选择目标岗位）
   - 8秒后自动隐藏提示

4. **数据处理**
   - 复用现有 blogParser.js 功能
   - 支持 Markdown frontmatter 格式
   - 智能合并和填充数据

### 📁 基本信息折叠功能

优化用户体验，将编辑器中的"基本信息"区域改为可折叠。

#### 功能特点

1. **默认折叠**
   - 首次打开页面，基本信息默认折叠
   - 节省屏幕空间，突出重点内容
   - 适合已完成信息填写的用户

2. **展开/折叠按钮**
   - 卡片标题旁显示紫色按钮
   - 清晰的展开/折叠图标
   - 悬停效果和动画

3. **平滑动画**
   - 展开时从上方滑入
   - 淡入效果，视觉流畅
   - 0.3秒过渡动画

4. **状态保持**
   - 用户手动展开后保持展开状态
   - 刷新页面后重置为折叠

## 🚀 使用指南

### 典型使用流程

#### 场景 1：完整新建简历

```bash
# 步骤 1：输入个人网站 URL
https://yourwebsite.com

# 点击"📥 抓取信息"
→ 基本信息自动填充（折叠状态）

# 步骤 2：选择岗位
点击"前端开发"或输入自定义岗位

# 点击"🚀 AI 优化简历"
→ 查看优化建议

# 步骤 3：微调（可选）
如需修改基本信息，点击"🔽 展开"按钮

# 步骤 4：导出
预览满意后，点击"📄 导出 PDF"
```

#### 场景 2：已有简历，优化岗位

```bash
# 跳过步骤 1（已有数据）

# 步骤 2：直接选择新岗位
输入或选择目标岗位 → AI 优化

# 微调内容
根据建议调整

# 导出
```
