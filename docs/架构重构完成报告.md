### 2. 博客数据导入 🆕

**支持的导入方式**:

#### ✅ 从本地文件导入

- 支持 .md、.markdown 文件
- 自动解析 YAML frontmatter
- 拖拽上传（未来版本）

#### ✅ 从 URL 导入

- 从任何公开的 Markdown URL
- 自动获取和解析内容
- 支持 GitHub Gist

#### ✅ JSON 数据导入

- 粘贴之前导出的数据
- 快速恢复简历
- 数据备份和迁移

**Markdown 格式示例**:

```markdown
---
name: 张三
title: 前端工程师
email: zhangsan@example.com
experience:
  - company: 某公司
    position: 工程师
    startDate: 2020-01
---

# 个人简介

这是我的简介...
```

**数据合并选项**:

```javascript
{
  overwriteBasicInfo: true,    // 覆盖基本信息
  appendExperience: false,     // 追加工作经历
  appendEducation: false,      // 追加教育背景
  overwriteSkills: true,       // 覆盖技能列表
}
```

```

├── Header (统计和导入功能)
├── ResumeEditor (左侧编辑区)

```

```
  ↓

```

## 🎓 学习要点

### 重构经验

1. **组件拆分原则**
   - 单一职责
   - 200-400 行最佳
   - 高内聚低耦合

2. **状态管理**
   - 使用 Pinia 集中管理
   - storeToRefs 避免重复渲染
   - useStorage 自动持久化

3. **工具函数设计**
   - 纯函数优先
   - 单一功能
   - 易于测试

4. **文件组织**
   - 按功能分类
   - 命名清晰
   - 结构扁平
